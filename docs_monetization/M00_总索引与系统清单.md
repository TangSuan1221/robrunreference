## 0. 一句话结论

**ROB RUN 的商业化不是"一个商店"，而是"三层货币 × 四类槽位 × 九条售卖面"的社会型经济**：

- **三层货币**：`Cash（物品）→ Credits（账户）→ B-Coin（付费硬币）`，中间由**银行 + 汇率市场**两个闸门控制；
- **四类槽位**：商店货架槽 / 据点建造槽（32 种）/ 生产设施子槽（显卡·散热·加速…）/ 仓储容器槽；
- **九条售卖面**：B-Coin 储值包、皮肤商店、Featured、战令 Premium、Premium+、单格直购、黑市解锁树、轮盘赌、无限奖励；
- **只有 1 条产生收入**（B-Coin 储值包），其余 8 条负责"消耗、留存、话题、闸门"；
- **价格几乎都不是钱**：据点用**物品**计价（15 条价格表），解锁树用 **Credits + 实物 + 刑期 + 区级**，轮盘用**现金**。
