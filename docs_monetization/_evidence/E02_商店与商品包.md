## 3. 定价体系

### 3.1 `CryptoCoinsPrice` 是唯一的"标价"字段吗？—— 是（对 ShopPack 而言）

| 结论 | 证据 |
|---|---|
| ShopPack 只有 1 个价格字段 `CryptoCoinsPrice : int`，**没有 Discount / BasePrice / SalePrice / Currency 字段** | `[实证] dump.cs:75886`（字段全集 75884-75894） |
| 价格是"B-Coin 数量"（整数），UI 用 `Money` 结构渲染（`Money { long Amount; Sign; Currency; … }`，`Currency` 含 `Crypto` 字形） | `[实证] dump.cs:1868717-1868723`、`1868770-1868775` |
| 按钮/价格文案都带参数化：`skin_center_buy_pack_button = "Buy {0}"`、`skin_center_pack_price = "$ {0}"` | `[实证] loc:skin_center_buy_pack_button`、`loc:skin_center_pack_price` |
| 视图侧 `SkinCenterShopPackView.SetPrice(Money value)` 接收 `Money`（不是 float/string） | `[实证] dump.cs:476530` |

> `skin_center_pack_price = "$ {0}"` 用 `$` 前缀，与"B-Coin 整数价"语义冲突，`[推断]` 为遗留/未启用 key（当前价格走 `Money` 的货币字形，见 `CurrencyDescription`）。列在 §9 待验证。

### 3.2 `GetPrice(pack, isFeatured, featuredPrice)` 的 featured 分支

```
public static int GetPrice(ShopPackDescription pack, bool isFeatured, int featuredPrice)   // [实证] dump.cs:158887
```

三条独立证据锁定 featured 价来源链：

1. **模型层**：`FeaturedPackModel` 持有 `Pack / EndTs / CryptoCoinsPrice` 三个只读字段（`[实证] dump.cs:480463`，字段 480466-480468）。即"被精选的包 + 该精选的结束时间 + 该精选的价格"是**服务端下发的三元组**。
2. **解析层**：`SkinCenterShopPacksLoadModelUpdater.TryParseCurrentFeaturedOffer(IReadOnlyList<IValue> offer, out ShopPackDescription pack, out int cryptoCoinsPrice)` —— 从响应里的一个**数组**解出 (pack, price)（`[实证] dump.cs:481174`）。方法名里 `Current` 说明是"当前这一档 featured"，数组第 0 位=包 id、第 1 位=价格 `[推断]`（仅凭 out 参数顺序推断，元素类型/顺序 `[未知-服务端]`）。
3. **规则层**：`SkinCenterShopPacksExtensions.GetCryptoCoinsPrice(model, description)` 与 `IsFeatured(model, description)`（`[实证] dump.cs:477031 / 477035`）——UI 取价时先问"这个包是不是当前 featured"，是则用 `FeaturedPack.CryptoCoinsPrice`。

⇒ `GetPrice` 语义 `[推断] 链：GetPrice(pack,isFeatured,featuredPrice) + FeaturedPackModel.CryptoCoinsPrice + TryParseCurrentFeaturedOffer ⇒ return isFeatured ? featuredPrice : pack.CryptoCoinsPrice`。
⇒ **featured 价不是折扣字段，而是"另一条独立报价"，由服务端在 `get_shop_packs` 响应里下发**；客户端不计算折扣 `[实证]`（`ShopPackRules` 中无任何折扣方法，`dump.cs:158866-158887` 全为 7 个方法）。

**"是否 featured"的判定不看 pack 自身**：`IsFeatured(model, description)` 只吃 model，说明 featured 是**货架态**而非商品属性 `[实证] dump.cs:477031`。

### 6.4 与 Steam 充值流程的关系（B-Coin 侧，独立管道）

`IPaymentsProcessor`（`[实证] dump.cs:445212`）：
`StoreInfo()` → `CreateOrder(TransactionTierDescription)` → `AuthorizeOrder(PurchaseModel)` → `FinalizeOrder(orderId)` / `CancelOrder` / `ConfirmDelivery(orderId)`。
实现类：`SteamOpsPaymentsProcessor`（后端 SteamOPS，`[实证] dump.cs:424911`）、`EmptyPaymentsProcessor`（`[实证] dump.cs:445151`）。
`PurchaseModel { Transaction, OrderId, TransactionId, State }`（`[实证] dump.cs:445319-445336`）。

⇒ **两条商业管道互不混合**：外观包 = `buy_shop_pack`（服务端货币扣减）；B-Coin = Steam 微交易 + 服务端发货 `[推断]`。

> ⚠️ 术语澄清（避免误读）：`PurchaseDeliveredNotificationUpdater` / `ConfirmDelivery(orderId)` 属于 **Steam 订单管道（B-Coin）**，需要玩家点 "Accept"（`[实证] loc:accept`）才确认收货。

## 10. 关键结论（确认的事实 + 最有价值的 3 条发现）

1. **一个 ShopPack 的身份＝`id`+`index`，商业化属性＝6 字段**：`Contents / CryptoCoinsPrice / AvailabilityStartTs / AvailabilityEndTs / IsPermanent / IsHidden`（`[实证] dump.cs:75909`）；派生出 `HasPrice`、`HasIndividualTimer`、`IsAvailableByTimer(now)`。
2. **Contents 只能装 10 种条目**：9 类外观（男/女体型、背包、面具、挂饰、武器涂装、表情、汽车、直升机）+ B-Coin；**只有 B-Coin 条目可重复获得**（`IsRepeatable` 与 `IsCryptoCoins` RVA 相同，`[实证] 0xFE4B70`）。单包件数无代码上限。
3. **34 个命名包已全部落地**：14 个主题套装（Drift…Wooden，专属头衔+长描述）+ 11 个面具单件 + 1 个背包单件 + 8 个武器涂装单件；单件包统一复用 `single_skin_pack_description`，且头衔直接复用外观名 key（`[实证] SO + loc`）。
4. **最有价值发现 A：外观包没有折扣系统，只有"featured 独立报价"**。`ShopPackDescription` 无任何折扣/原价字段，`GetPrice(pack, isFeatured, featuredPrice)` 的 `featuredPrice` 由服务端 `get_shop_packs` 的当前 featured 数组下发（`TryParseCurrentFeaturedOffer → FeaturedPackModel.CryptoCoinsPrice`）。折扣 `Discount:float` 只存在于 B-Coin 充值包（`[实证] dump.cs:63928`），属另一条商业管道。
5. **最有价值发现 B：外观包不走 Steam 微交易**。`TransactionDescriptions` 只实例化了 6 条 B-Coin 交易（`CryptoCoinsPack0..5` → `Tier499..Tier4999`），`TransactionDescription.ShopPackFunc` 是空挂字段；外观包只花 B-Coin、由服务端消息结算。Steam 侧只负责卖 B-Coin（`StoreInfoResponse.transaction_tiers` 白名单 + `MicroTxnAuthorizationResponse_t` 回调 + `IPaymentsProcessor` 五步订单流）。
6. **最有价值发现 C：货架是"1 个 featured 槽 + N 个 set 档 + 一份包列表"三层结构**，且配置真值可读：主菜单轮播 `WidgetMaxPacks = 5`、计时器"即将结束"阈值 `LastMinForAttentionTimer = 30` 分钟、预览格子间距 72/16（`[实证] SO`）；B-Coin 页签固定 6 档。
7. **失败处理极简**：`ShopPackErrors` 只有 `price_out_date` 一个错误码，客户端收到即静默重拉货架；余额不足、已拥有等全靠客户端预检（`HasOwnedItems` / `CanGrant` / `HasAnythingToGrant`）。
8. **补偿＝把已拥有的外观按条目单价折成 B-Coin**（`CalculateCompensation` 返回 int + `ShopPackItemDescription.CompensationCryptoCoins` + 弹窗 "{1} in compensation"），说明"重复购买"在客户端被设计为**部分补偿**而非禁止。
9. **无法从 dump 取到的真值集中在 3 处**：`ShopPackDescriptions..cctor`（RVA `0x398CC00`，含 34 包的 contents/价格/时间窗/隐藏位）、`get_CompensationCryptoCoins`（`0x40A1E40`）、`get_shop_packs` 服务端响应结构——已在 §9 给出逐条入口，未做任何数值猜测。
