### 2.4 `AmountStep`（Steam 各币种充值步长）如何影响档位

| 事实 | 证据 |
|---|---|
| `SteamCurrencyDescription` 只有 3 个字段：`id / index / AmountStep` | `[实证] dump.cs:75819-75836`（字段仅 `AmountStep` @0x20，ctor `(string id,int index,int amountStep)`） |
| `AmountStep` 是**每个币种一个整数**，随币种定义（`SteamCurrencyDescriptions.New(string id,int amountStep)`） | `[实证] dump.cs:28774` |
| 唯一消费点是 `PaymentsRules.TryGetPrice` → `GetPriceCurrency` | `[实证] dump.cs:445446/445452`（grep `AmountStep` 全库仅命中 `dump.cs:75823/75826/75835`；`SteamCurrencyDescriptions.New(string id, int amountStep)` 见 `dump.cs:28774`） |
| 语义 | `[推断]` 推理链：①价格表 `SteamPriceAmounts` 是"整数最小单位"；②`TryGetPrice` 返回 `(currency, amount)`；③若某币种（如 RUB）只允许整十/整百价位，则需要把价目"对齐到 step"，否则 Steam 结算会拒绝/取整。故 `AmountStep` = **该币种的可用价位粒度**，客户端用它把 tier 金额折算/校验成该币种合法价目。 |
| 对"档位"的影响 | `[推断]` 档位数量（6）由 `TransactionTierDescriptions` 固定，**AmountStep 不增减档位**，只影响**同一档在不同币种下的实际显示金额**（可能被对齐而偏离 499/999… 的等比关系）。具体数值 `[未知]`（2 个币种的 step 都在 `.cctor dump.cs:28785` 里） |

| 下注额编码 | `RouletteModel.MaxAmountPerChip = 4095`（12 bit：`Encode/Decode(long, in Span<int>)` 把多注金额压进一个 `long`） | `[实证] dump.cs:159744, 159816-159819` |

**能不能从客户端算出抽水/期望值？——分三层回答：**

1. **轮盘几何 `[实证]`**：37 格（0–36），等概率 → `P(单号) = 1/37`。
2. **标准赔率下的 RTP `[推断-数学]`**：若 `Odds[Straight] = 36`（含本金的 36 倍返还），则
   - `RTP(Straight) = 36 × (1/37) = 36/37 = 97.297%` → **庄家优势 2.703%**
   - 其他注型若遵循欧式标准（Split 18、Street 12、Corner 9、SixLine 6、Dozen/Column 3、Even-money 2），RTP 全部同为 `36/37`（这是欧式轮盘的恒等式）。
   - 公式（可复算）：`RTP(type) = Odds[type] × P(type)`，`P(type) = 覆盖号码数 / 37`；`HouseEdge = 1 − RTP`。
   - 校验恒等式：`Odds × 覆盖数 = 36` 对所有标准注型成立 → **只要策划不做"优待注型"，抽水恒为 1/37 = 2.70%**。
3. **实际抽水 `[未知]`**：`Odds` 的 12 个整数写在 `RouletteBetOddsConfigs..cctor`，**客户端拿不到**。因此：
   - 若 `Odds[Straight] ≠ 36`（例如 35 表示"净赢 35 倍、本金另退"，或 34 做暗抽水），实际 RTP 会偏离 36/37；
   - 整数语义（**总返还倍数** vs **净赢倍数**）同样不可辨 → **必须反编译 `.cctor` 或抓包才能定量**。
   - 另外 `[推断]`：`MaxRewardAmount`（`dump.cs:78060`）会对超高倍命中做**截断**，这也会实际压低 RTP，但其值 `[未知]`。

> 一句话：**"轮盘的抽水 = 1/37" 只在"标准欧式赔率"假设下成立；ROB RUN 的真实抽水无法从 dump 得出**（缺 `Odds` 12 个整数 + `MaxRewardAmount` + `MaxBetAmount`）。这是本文件最诚实的结论。

## 10. 复刻要点（策划可直接抄的 8 条）

1. **真钱只开一个口子**：所有外观定价用付费币（B-Coin），真钱只卖付费币包；轮盘/黑市不收真钱，规避博彩与 P2W 指控。`[实证] dump.cs:75886 / 71287 / 325629`
2. **6 档常青货架 + 6 个价档**：$4.99/9.99/14.99/19.99/29.99/49.99（`[推断]`），档位只加"赠送币率"与"折扣"，**不限购、不限时、无首充**——把"稀缺感"留给皮肤包（限时 + 每日 featured + 最后 30 分钟变色）。`[实证] dump.cs:28205-28215 / 75888 / SO LastMinForAttentionTimer=30`
3. **缺币补购按缺口选最小包**：把付费墙放在"差一点点"的瞬间。`[实证] ShowCoinsPackRules.TryGetCoinsPack(needCoins)` `dump.cs:448558`
4. **付费买"外观+时长"，买不到"资历"**：几乎所有外观都带 `imprisonmentYearsRequired`，黑市节点带 `RequiredImprisonmentYears` → 钱解决不了刑期门槛。`[实证] dump.cs:24754 / 71289`
5. **赌场只发筹码、不发钱**：筹码是道具、占背包、1:1 换 cash（`[推断]`），赢钱要跑回庄家领（"Collect your winnings from the dealer"）→ 物理摩擦 = 现金回收减速带。`[实证] dump.cs:325629 / loc`
6. **大赢全服广播带昵称+公会**：把"赢"变成社交货币，驱动围观者下注。`[实证] dump.cs:233586-233592 / loc:big_win_notification`
7. **无限奖励=赛季货币的唯一出口**：BP 货币赛季清零 + "no purchase limit" + 隐藏奖池 → 逼当期消费；且它**不能真钱买**，只能打。`[实证] dump.cs:129905 / loc:383,348`
8. **解锁树用"迷雾+世界观话术"包装价格**：未解锁显示 `Unknown Item`（配一句"监狱是犯罪的大学"），成本 tooltip 叫 **"Laptop price:"**，把"付钱"说成"买笔记本的价"。`[实证] loc:4758 / 4771-4772`
