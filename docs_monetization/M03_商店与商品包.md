# M03 · 商店与商品包（ShopPack / 货架 / Featured / 补偿）

> **一句话**：商店卖 34 个**外观打包**，只有一个价（B-Coin 整数），**没有折扣字段**；"限时特价"只能靠服务端下发的 **featured 独立报价**实现。外观包**不走 Steam**，只花 B-Coin。
> **证据**：E02（584 行证据）+ 本文复核行号。凡与早期草稿冲突处，以本文为准（已在 §11 标出修订）。

---

## 0. 一页结论（10 条）

1. **商品包身份 = `id` + `index`**（`MyEnumItem`），商业化属性只有 6 个字段：`Contents / CryptoCoinsPrice / AvailabilityStartTs / AvailabilityEndTs / IsPermanent / IsHidden`；派生 `HasPrice / HasIndividualTimer / IsAvailableByTimer(now)`。`[实证] dump.cs:75880-75943`
2. **Contents 只能装 10 类**：9 类外观（男体/女体/背包/面具/挂件/武器涂装/表情/车/直升机）+ **B-Coin**；**只有 B-Coin 条目可重复获得**（`IsRepeatable` 与 `IsCryptoCoins` 编译到同一 RVA `0xFE4B70`）。单包件数**无硬编码上限**。`[实证] dump.cs:76055-76109`
3. **34 个命名包**：14 主题套装 + 11 面具 + 1 背包 + 8 武器涂装。其中 **20 个单件包复用同一条描述文案** `single_skin_pack_description`，头衔直接复用外观道具名。`[实证] dump.cs:29342-29449 + SO`
4. **只有一个价格字段**：`CryptoCoinsPrice : int`。**没有** `Discount / BasePrice / SalePrice / Currency` 字段，客户端也不做任何折扣计算。`[实证] dump.cs:75886；ShopPackRules 仅 7 个方法，无折扣方法`
5. **featured 价是"另一条独立报价"**：服务端在 `get_shop_packs` 响应里下发 `[packId, price]` 二元组 → `FeaturedPackModel{Pack, EndTs, CryptoCoinsPrice}`；`GetPrice(pack,isFeatured,featuredPrice)` 只做二选一。`[实证] dump.cs:480463-480468、481174、158887`
6. **折扣（`Discount:float`）只属于 B-Coin 储值包**，且是**客户端常量**（`CryptoCoinsPackDescriptions..cctor`）。真实货币价格串来自 `TransactionTierDescription.SteamDescriptions`。`[实证] dump.cs:63928、477276-477300、74319`
7. **两条商业管道严格隔离**：`TransactionDescriptions` 只实例化 6 条 B-Coin 交易（`CryptoCoinsPack0..5`），**没有任何 ShopPack 交易**；外观包只走 `buy_shop_pack` / `buy_featured_shop_pack` 消息。`[实证] dump.cs:28142-28152`
8. **货架三层**：**1 个 Featured 槽**（单例）+ **N 个 Set 档**（同 `EndTs` 分组）+ **1 份包列表**；另有主菜单轮播 **≤5**、B-Coin 页 **6 档**、分类页签 **12 个变体**。`[实证] dump.cs:480352-480358、480450-480454、SO:WidgetMaxPacks=5`
9. **计时器真值**：`LastMinForAttentionTimer = 30` 分钟（进入 `ExpiringSoon` 紧急色）、`shop_pack_timer = "{0:time:stadh}"`、预览间距 `72/16`。`[实证] SO + loc`
10. **错误只有一条**：`price_out_date`。客户端收到后**静默重拉货架**（不弹错），这是"价格随时可变"的工程实现。`[实证] dump.cs:17759-17763 + E02 §7`

## 4. 定价体系（本作最反直觉的一处）

### 4.1 只有一个价，且没有折扣

| 对象 | 价格字段 | 折扣字段 |
|---|---|---|
| `ShopPackDescription` | `CryptoCoinsPrice : int` | **无** |
| `CryptoCoinsPackDescription` | 无（价格在 Tier） | **`Discount : float`** |

`[实证] dump.cs:75884-75894（字段全集）、63922-63928`

### 4.2 featured 价 = 服务端下发的独立报价

```
get_shop_packs 响应
  └─ current featured offer = [packId, cryptoCoinsPrice]
        → FeaturedPackModel{ Pack, EndTs, CryptoCoinsPrice }
              → GetPrice(pack, isFeatured, featuredPrice) = isFeatured ? featuredPrice : pack.CryptoCoinsPrice
```

`[实证] dump.cs:481174（TryParseCurrentFeaturedOffer）、480463、158887、477031/477035`

**设计含义**：**"限时特价"不是打折，是换价**。运营改的是"这个包在 featured 位的报价"，而不是"给这个包加一个 5 折字段"。好处：① 不污染商品主价 ② 可以做"涨价促销"（featured 价高于原价）③ 客户端永远算不出折扣逻辑。

### 4.3 `$ {0}` 的真相

`skin_center_pack_price = "$ {0}"` 与"B-Coin 整数价"语义冲突；而视图侧 `SetPrice(Money value)` 收的是 `Money`（带币种字形），价格用它渲染。→ **该 key 极可能是遗留/未启用**（不是美元直购）。外观包**没有任何真实货币入口**。`[实证] dump.cs:476530、1868717-1868723；[推断] key 未使用`

### 4.4 真实货币价格链（只服务 B-Coin 包）

`TransactionDescription → TransactionTierDescription{ SteamProductId, SteamPriceAmounts, SteamDescriptions }`；UI 的 `SetPrice(string priceText, float discountPercent)` 两个入参分别来自 **`SteamDescriptions` 的成品串** 与 **`CryptoCoinsPackDescription.Discount`**。`[实证] dump.cs:74257-74277、74315-74330、477397`

> 所以：**外观包 = B-Coin 单锚；储值包 = 真钱 + 折扣 + 赠币 三锚**。两套定价逻辑不能混。

## 6. 重复购买与补偿

**机制**：买包时若已拥有其中某些外观 → 服务端把已拥有条目的 `CompensationCryptoCoins` **累加**折成 B-Coin 返还；弹窗文案 `Some items in {0} are already in your collection. You will receive {1} in compensation.`；闸门 `HasAnythingToGrant / CanGrant`。

`[实证] dump.cs:158875（CalculateCompensation 返回 int）、76109、loc:skin_center_shop_pack_modal_parts_description`

**设计读法**：
- 补偿是 **B-Coin**（平台内代金券），不是现金；
- 不惩罚收集者 → 降低差评；
- 公式不公开（RVA `0x40A1E40` 可反汇编）。

## 8. 设计读法（7 条）

1. **外观是"轮换货架"，储值是"常青货架"**：稀缺感全放在皮肤侧（时间窗/featured/30 分钟紧急色），储值侧只做"稳定价位 + 赠币递增"。
2. **没有折扣字段反而是优势**：运营用 featured 报价实现一切价格操作，商品主价永远干净，玩家也比不出"史低"。
3. **打包提高客单价，单件做引流**：14 套装拉高客单，20 单件（面具/背包/武器皮）做低价入口与图鉴收集。
4. **补偿机制是长线外观经济的安全阀**，且返的是 B-Coin（钱留在体系内）。
5. **两条管道隔离**（Steam 只卖币，外观只花币）让"外观定价"完全自主，不受 Steam 促销日历约束。
6. **错误只有 `price_out_date` 且静默重拉**：把"价格会变"这件事做进了协议层，而不是弹窗打扰玩家。
7. **"不卖数值"写进文案**，是复刻时的红线。
