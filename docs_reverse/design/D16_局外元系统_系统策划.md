# D16 · 局外元系统（系统策划）

> **对应技术文档**：`../tech/16_局外元系统_技术实现.md`
> **标记**：`【原作】` / `【推断】` / `【补全】`

---

## 1. 元系统的任务：把"系统"变成"体验"

局外系统有 16 个子系统，但玩家只感知到 5 种体验：

| 体验 | 元系统 |
|---|---|
| "我知道该干什么" | 教程 |
| "我懂了这个世界" | Codex |
| "我有长期目标" | 战令 / 成就 |
| "我被通知了" | 邮件 / 全局通知 |
| "我被保护了" | 举报 / 维护 / 校验 |

---

## 2. 教程：从"监狱"开始的叙事化教学

**15 步完整链**（`【实证】`）：

```
监狱段：纹身对话 → 纹身 → 越狱对话 → 越狱
Hub 段：开场对话 → 租车 → 上车 → 离开
城市段：进入 → 变身罪犯 → 首次抢劫 → 离开
Hub 段：结束对话 → 完成
```

**为什么从监狱开始**（`【推断】`）：
1. **叙事合理**：你是罪犯，刚出狱/越狱
2. **教学合理**：监狱是"最安全"的地方，适合教基础操作
3. **情绪**：一开始就"逃出来"，给玩家一个高潮开场

**设计铁律**：
> 教程的每一步都必须"玩家已经在做这件事"，而不是"先讲再让玩家做"。

---

## 3. Codex：强制阅读的"游戏百科"

`CodexViewDescription.IsMandatory` 说明**有些页必须看**。

**设计意图**（`【推断】`）：
- 新机制解锁时，强制弹一页图鉴（确保玩家知道）
- 老玩家可以跳过（非 Mandatory）
- 图鉴是"机制说明书"的最后一道保险

**内容分类**（`【实证】`）：
- 普通 Codex 页（物品/机制）
- Buff 页（`CodexBuffsDescription`）

---

## 4. 战令：长期目标

**结构**：`赛季 → 页 → 行 → 奖励`。

**与据点系统的关系**（`【推断】`）：
- 战令奖励里应该有 **Land Plot Title / Settlement Title**（地券/聚落券）
- 这是"不花钱也能拿到地"的渠道
- 也是"地券供给"的可控阀门（D04 §5.1）

---

## 5. 通知：分层的"世界在发生什么"

**两层**（`【实证】`）：
- `ClientNotification`：客户端本地（如"你被瞄准了"）
- `GlobalNotificationModel`：服务端广播（如"某人的基地被入侵"）

**关键通知类型**（`【实证】`）：
- `PlotAlarm`（基地被入侵）
- `VendorTreeNodeAvailable`（新解锁）

**设计含义**：**通知不是"系统消息"，是"世界事件"**。玩家收到"某人的基地在危险中"，会感觉世界在运转。`【推断】`

---

## 6. 维护/停服：不能"突然消失"

**原作**：`MaintenanceScreenModel` + `ServerShutdownNotifications`（6 类）。

**设计意图**（`【推断】`）：
- 停服前有**倒计时通知**（`ServerShutdownNotifications`）
- 停服时是**全屏维护屏**，不是"连接失败"
- 玩家不会觉得"游戏坏了"

---

## 7. 举报与改名：社区治理

**举报维度**（`【实证】`）：
- 聚落名
- 玩家名

**改名规则**（`【实证】`）：
- 聚落名 5 条校验（长度/纯数字/特殊符号/首尾空格/连续空格）
- 玩家名/帮派名共用 `NicknameValidationDescription`

**设计含义**：**命名是"社会契约"**。校验 + 举报 = 让玩家自己维护环境。`【推断】`

---

## 8. 与其他系统的耦合

| 元系统 | 与局外系统的耦合 |
|---|---|
| 教程 | 强制走 D01 的玩家旅程 |
| Codex | 记录 T06/T07/T09 的所有机制 |
| 战令 | 奖励地券/聚落券 |
| 邮件 | 通知税可收/基地被入侵 |
| 通知 | 警报/解锁 |
| 维护 | 赛季结束/停服 |
| 举报 | 聚落名/玩家名 |

## 9. 测试边界（本系统 18 条）

1. 教程 15 步顺序正确
2. 教程每步的提示/子提示/地图高亮
3. 教程完成 → 弹完成对话框
4. 教程中途断线 → 恢复
5. `IsMandatory` 的 Codex 页强制弹出
6. Codex 页签切换（普通/Buff）
7. 战令赛季/页/行/奖励 四级结构
8. 战令奖励领取
9. 战令付费/免费轨道
10. 邮件列表/详情/领取
11. 全局通知不刷屏
12. `ClientNotification` 与 `GlobalNotification` 分层
13. 维护屏出现
14. 停服倒计时通知
15. 举报聚落名
16. 聚落名 5 条校验
17. 玩家改名校验
18. 弹窗单例（不叠加）

---

## 10. 复刻时的三个"反直觉决定"

1. **教程从监狱开始** —— 直觉上"教程应该在新手村"，但"越狱"给了一个叙事高潮。
2. **Codex 可强制** —— 直觉上"图鉴应该可选"，但强制阅读是"机制不被误解"的最后保险。
3. **通知是"世界事件"** —— 直觉上"通知只是提示"，但"某人的基地在危险中"让世界显得活着。
