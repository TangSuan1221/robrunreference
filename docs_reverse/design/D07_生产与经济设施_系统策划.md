# D07 · 生产与经济设施（系统策划）

> **对应技术文档**：`../tech/07_生产与经济设施_技术实现.md`
> **标记**：`【原作】` / `【推断】` / `【补全】`

---

## 1. 生产系统在游戏里的位置

玩家在据点里做的所有事，最终都服务于一个**闭环**：

```
出去抢/买 → 带回来未处理的东西 → 在据点里加工 → 变成值钱的东西 → 卖掉换脏钱 → 洗成净钱
```

**生产设施就是这个闭环的"加价环节"**。没有它们，玩家只是"搬运工"；有了它们，玩家是"工厂主"。

**设计铁律**：
> 每一种"原始货物"都必须有一条"加工路径"，且加工后的价值必须 > 直接卖的价值 × 加工时间成本。

否则玩家会直接卖原料，生产设施变成摆设。`【推断】`

---

## 2. 七类设施的功能定位

| 设施 | 一句话 | 玩家在什么阶段用 |
|---|---|---|
| **开箱台** | 把抢来的箱子打开 | 每次抢劫回来 |
| **贸易台** | 把货重新打包卖更贵 | 有稳定货源后 |
| **生产台** | 用试剂造货 | 中期，需要配方 |
| **充电/催熟台** | 让作物/晶体"长成" | 中期，被动 |
| **加密矿机** | 被动产出加密货币 | 后期（未完成） |
| **洗钱台** | 脏钱 → 净钱 | 每天上线都要用 |
| **采集台** | 做收集品 | 长期养成 |

---

## 3. 玩家旅程：一天的生产循环

| 时间 | 玩家动作 | 设施 | 产出 |
|---|---|---|---|
| 上线 | 收昨天的产出 | 采集台/充电台/加密矿机 | 收集品/成熟作物/币 |
| 5 分钟 | 开箱 | 开箱台 | 半成品 |
| 10 分钟 | 重打包 | 贸易台 | 高价成品 |
| 15 分钟 | 出门卖货 | — | 脏钱 |
| 20 分钟 | 洗钱 | 洗钱台 | 净钱 |
| 30 分钟 | 出门抢劫 | — | 新箱子 |
| 下线前 | 投料 | 生产台/充电台 | 明天的产出 |

**节奏目标**：**上线 30 分钟能跑完一轮"收→开→包→卖→洗"**。如果一轮超过 1 小时，玩家会疲劳。`【推断】`

---

## 4. 三种升级路线（这是最值得抄的设计）

ROB RUN 的设施升级不是"升级一次加一点"，而是**三条互斥的路线**：

| 路线 | 效果 | 适合谁 |
|---|---|---|
| **速度** | 更快完成 | 高频玩家 |
| **容量** | 一次处理更多 | 挂机玩家 |
| **效率/结构** | 更省资源 / 更好的产出 | 精算玩家 |

**为什么互斥很重要**：如果三条路线能同时满，玩家就没有选择，设施变成"数值堆叠"。互斥让每台机器都有**流派**。`【推断】`

**复刻建议**（`【补全】`）：
- 每台设施 **2–3 个升级槽**
- 每个槽只能装一类升级件
- 升级件是**物品**（可交易），不是"点数"

---

## 5. 时间尺度设计（最关键的一节）

ROB RUN 的所有设施都遵循"tick 驱动"：

```
一个 tick = 固定时长
一次产出 = N 个 tick
产出物 = 在 tick 结束时生成
```

**为什么用 tick 而不是"进度条"**：
- **可预算**：玩家能算出"我 2 小时后回来正好满"
- **可离线**：服务端算 tick，不依赖玩家在线
- **可被抢**：产出在 tick 结束时落在地上，谁在谁拿

**数值建议**（`【补全】`）：

| 设施 | tick 设计 | 理由 |
|---|---|---|
| 开箱台 | 每次 30–120 秒（按箱子等级） | 短，让开箱有节奏 |
| 贸易台 | 每件 60 秒 | 中 |
| 生产台 | 一次 10–30 分钟 | 长，鼓励挂机 |
| 充电台 | 一次 30–120 分钟 | 最长，睡觉回来收 |
| 洗钱台 | 每 1 小时洗一批 | 按小时，日循环 |
| 采集台 | 每 30 分钟一个收集品 | 中等 |

**校验**：所有周期都应该是 **"玩家一次上线（30 分钟）能收完 1–2 轮"** 的量级。`【推断】`

---

## 6. 产出为什么必须"落在地上"

**原作**：所有工作台都有 `SpawnLootPoint`，产出物出现在**工作台外**，玩家要长按拾取。

**设计含义**（`【推断】`）：
1. **风险**：产出暴露在可被抢的空间
2. **戏剧性**：正好有人来抢，你正在捡
3. **反挂机**：不能"离线自动进背包"

**复刻建议**：**永远不要**让产出直接进背包。哪怕是最安全的设施，也要有"拾取"动作。`【补全】`

## 7. 七类设施的具体玩法

### 7.1 开箱台

- **输入**：各种"未开封"的箱子（`SealedCrate` / `CashBag` / `Suitcase` / `Safe`…）
- **输出**：随机物品
- **升级**：加槽（同时开多个）+ 加速（更快开）
- **加速件的"槽类型"限制**：拆箱工具只能装拆箱槽，不能装别的
- **玩家决策**：先开哪个箱子？（高价值但慢 vs 低价值但快）

### 7.2 贸易台

- **输入**：违禁品（从 Looty Bay / Lenny's Motel / Distribution Center 买）
- **输出**：重打包后的高价货
- **升级**：加槽 + 加速
- **联动**：聚落公共建筑"黑市"（`building_bonus_blackmarket`）能提高重打包利润
- **玩家决策**：这条货值不值得重打包？

### 7.3 生产台

- **输入**：试剂（`Reagents`）
- **输出**：晶体/毒品等成品
- **升级**：改产出权重（装引擎/温度计/转换器 → 产出偏向不同）
- **玩家决策**：我要产哪种货？
- **联动**：实验室（`building_lab_1`）加速整个烹饪周期

### 7.4 充电/催熟台

- **两种台型**：花园床（种植物）、工业冷冻机（冻晶体）
- **输入**：种子/液体
- **输出**：成熟作物/硬晶体
- **升级**：加速
- **联动**：蓄水池（`building_farm_1`）给"额外收成概率"
- **玩家决策**：种什么？什么时候收？

### 7.5 加密矿机

- **输入**：显卡（`VideoCardSlots`）+ 散热（`CoolingSlots`）+ 加速（`SpeedupSlots`）
- **输出**：加密货币
- **升级**：效率（降消耗）、速度
- **状态**：**原作未完成**（"in development"）
- **玩家决策**：值得投资吗？

### 7.6 洗钱台

- **输入**：脏钱（`DirtyCash`）
- **输出**：净钱（`CleanCredits`）
- **上限**：`MaxDirtyCashAmount`（超过会出"大便堆"事件？）
- **升级**：加速（`DirtyCashPerPeriodModifier`）
- **联动**：聚落公共建筑（`building_owner_bonus`）提高洗钱率
- **玩家决策**：什么时候洗？洗多少？

### 7.7 采集台

- **输入**：无（或收集品材料）
- **输出**：收集品（Collection）
- **三段交互**：操作 → 生成 → 拾取
- **升级**：3 档模块（Uncommon/Rare/Legendary）解锁更多收集
- **玩家决策**：先做哪套收集？

## 8. 与其他系统的耦合

| 系统 | 耦合 |
|---|---|
| 建造 | 工作台是建造物品，放在槽里 |
| 经济 | 生产链 = 加价链 |
| 税 | 洗钱流水是税基 |
| PvP | 产出落在地上，可被抢 |
| 聚落 | 公共建筑给生产加成 |
| 载具 | 货物要用车运 |
| 贸易 | 成品的卖点（Looty Bay/Smuggler） |

## 9. 反作弊与边界情况

| 风险 | 防护 |
|---|---|
| 脚本刷开箱 | 服务端 tick + 加速件限制 |
| 离线挂机自动收 | 产出落在地上，必须手动拾取 |
| 用低价值货刷贸易 | 重打包有成本和上限 |
| 洗钱台无限囤 | `MaxDirtyCashAmount` |
| 生产台刷权重 | 权重件是物品，有数量限制 |
| 采集台刷收集 | 收集品按套收集，不能重复 |

## 10. 测试边界（本系统 24 条）

**开箱台**

1. 放箱子 → 开始开 → 完成 → 产出落在 `SpawnLootPoint`
2. 开箱中被入侵 → 产出可被抢
3. 加槽升级 → 槽位 +1
4. 加速升级 → 时间缩短，且只对匹配槽类型生效

**贸易台**

5. 放违禁品 → 重打包 → 增值
6. 无黑市建筑 → 基础价；有黑市 → 加价
7. 加槽/加速升级各自独立生效

**生产台**

8. 投料 → tick × count 后产出
9. 换权重件 → 产出偏向变化
10. 中途"排料"（`cargo_production_stop_action`）→ 试剂退回

**充电台**

11. 放种子 → 周期到 → 成熟
12. `CanCollectChargedCargoReward` 开启时，可收额外奖励
13. 蓄水池加成 → 额外收成概率

**加密矿机**

14. 装显卡 → 开始产出
15. 装散热 → 资源消耗降低
16. 缺散热 → 效率下降/停机（`[未知]`）

**洗钱台**

17. 脏钱 ≤ 上限 → 正常洗
18. 脏钱 > 上限 → 溢出/暂停（`[未知]`）
19. 洗钱电缆被打断 → 需修复（`RepairBrokenCableDuration`）
20. 加速件 → `DirtyCashPerPeriodModifier` 提高

**采集台**

21. 操作 → 奖励生成在 `RewardPosition`
22. 拾取 → 收集品入包
23. 升级模块 → 解锁新收集
24. 收集完成 → 奖励/图鉴解锁

---

## 11. 复刻时的三个"反直觉决定"

1. **产出必须落在地上** —— 直觉上"生产完自动进背包"更省事，但那会让"被抢"失去意义。
2. **升级三条路线互斥** —— 直觉上"都能升满"更爽，但那会让设施变成数值堆叠，失去流派。
3. **洗钱台有容量上限** —— 直觉上"无限囤"更方便，但那会让玩家永远不回来（囤到州末一次性洗）。
