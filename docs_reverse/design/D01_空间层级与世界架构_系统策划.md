# D01 · 空间层级与世界架构（系统策划）

> **对应技术文档**：`../tech/01_空间层级与权威流_技术实现.md`
> **读法**：本文只讲"这个系统是什么玩法、玩家怎么感知、需要测什么边界"。所有机制名都对应 T01 的字段/文案，可回查。
> **标记**：`【原作】` = ROB RUN 实证；`【推断】` = 由原作结构推出的设计意图；`【补全】` = 原作没有、为方案成型补的设计

## 1. 这个系统到底在卖什么

一句话：**它卖的是"一块能被别人惦记的地"。**

玩家感知不到"Region/Realm/Sector/Settlement/Plot/Slot"这六层，他只感知到四件事：

1. **我在哪个州**（和谁一起玩、还剩几天）
2. **我在哪个区**（能买什么、能不能买地）
3. **我住在哪个聚落**（谁是我房东、谁会来抢我）
4. **我的家有多少格**（能建什么）

所以，"世界架构"的策划任务不是画地图，而是**让每一层都有一个玩家能说出口的数字**：

| 层 | 玩家嘴里的说法 | 系统要给的数字 |
|---|---|---|
| Region | "我在亚服" | 延迟 + 好友在不在 |
| Realm | "这个州还剩几天" | 剩余寿命、人口、是否老州 |
| Sector | "这是三区，东西好" | Tier、能否买聚落、可买物品等级 |
| Settlement | "这个聚落有主，房租多少" | 有无主、税额、公共建筑 |
| Plot | "我家 24 格" | 地块数、蓝图、已建/未建 |
| Slot | "主屋 8 个箱子位" | 32 类槽位的可用性 |

**设计铁律**：任何一层如果没有一个可显示的数字，它就是 UI 噪声，应当删掉。`【推断】`

## 2. 玩家旅程（首次进入 → 有家 → 有产 → 终局）

以 ROB RUN 的实证教程链为骨架（`tutorial_*` 文案全部可核对）：

| 步 | 玩家在做什么 | 系统必须给出的反馈 | 对应文案证据 |
|---|---|---|---|
| 1 | 主菜单选州 | 州列表（ID/名称/人口/寿命/负载/是否有好友） | `realm_entry_*`、`switch_realm_*` |
| 2 | 进入州，落在地图 | 全局地图（District/Settlement 两层） | `hints_location_enter_*` |
| 3 | 想进聚落，被拒 | "先买块地" | `realm_notification_player_has_no_home` |
| 4 | 拿到 Land Plot Title，租地 | 弹出地块点阵，选中一块 | `tutorial_plot_builder_step_description` = "Rent a land plot" |
| 5 | 放主屋 | 主屋出现，内有 8 储物位 | `tutorial_main_building_step_description` = "Place a house onto the Plot Plan" |
| 6 | 放车 | Key Locker 出现钥匙位 | `tutorial_set_car_step_description` = "Place a car in the Key Locker" |
| 7 | 出聚落进城 | 首次进 Looty Bay | `tutorial_leave_settlement_step_description` = "Leave the settlement" |
| 8 | 变罪犯抢劫 | 通缉度上升 | `tutorial_become_robber` = "Find a deserted place and become a Criminal" |
| 9 | 回基地洗钱 | 脏钱→净钱 | `tutorial_clean_cache` = "Launder cash to obtain clean credits" |
| 10 | 被入侵/入侵别人 | 警报、防御块、Raid Lock | `global_notification_plot_alarm_*` |
| 11 | 州末联邦没收 | 全资产清算 → 服刑/威望 | `popup_confiscation_*` |

**节奏判据**：第 4 步（拿到第一块地）必须发生在**首次进入后 15 分钟内**，否则玩家会觉得"这游戏不给我东西"。ROB RUN 通过教程强制 + 地券掉落做到这一点；复刻时**不要把这个门槛抬高**。`【推断】`

## 3. 每一层的玩法功能（设计说明书）

### 3.1 Region：延迟域，不是服务器

**玩法**：玩家选"亚服/欧服/美服"，系统给一个延迟最优的推荐。

**为什么存在**：让"和朋友一起玩"和"打得动"能兼顾。

**约束**（`【原作】`）：换区只能在监狱里。这条把"换区"从"菜单操作"变成"服刑期决策"，避免玩家在帮战中途逃到别区。

**测试边界**：

| # | 场景 | 预期 |
|---|---|---|
| R1 | 在野外点"换区" | 拒绝，提示 "You can change your region only in prison" |
| R2 | 服刑中换区 | 允许；换区后原州关系（帮派）应失效 |
| R3 | 换区后好友列表 | 好友仍在（跨区），但"同州"标记消失 |
| R4 | 延迟展示 | `region_ping_dropdown_template` = "{0} ({1}) {2}"——三个占位符都要有值（区名/延迟/负载） |
| R5 | Fallback 区 | `region_name_fallback` = "Fallback" 不得显示为空 |

### 3.2 Realm/State：一台有寿命的服务器

**玩法**：玩家看到州列表，选择"新州（[New]）/推荐/有人/负载低"。

**核心决策**：新州 = 所有人从零开始，机会多；老州 = 别人已经建好，但可能"进度差距大"（`switch_realm_not_fresh_warning`）。

**为什么需要"寿命"**：这是**终极平衡器**——不管谁滚雪球，7 天后一切清零重来。`【推断】`

**约束**（`【原作】`）：
- 换州会**退帮**（`switch_realm_in_clan_warning` = "If you change your state, you will leave your clan."）
- 换州会**丢失本州进度**（`switch_realm_lost_progress_warning`）
- 老州有风险提示（`switch_realm_not_fresh_warning`）

**测试边界**：

| # | 场景 | 预期 |
|---|---|---|
| S1 | 列表刷新 | 受 `RealmsListExpiringResource` 配额限制，不能无限刷 |
| S2 | 按 ID 搜索 | 输入非法长度/非法区 → 三种不同错误（`realm_id_input_invalid_length/_region/_realm`） |
| S3 | 满员州 | 显示 "Full"（`switch_realm_full_load`），不可进 |
| S4 | 只剩 1 分钟寿终 | 应展示终局倒计时，禁止"刚进就清算"的误伤（`realm_entry_old_realm_tooltip_description` = "Less than {0} remaining until the federal raid"） |
| S5 | 换州时在帮派里 | 二次确认必须写明"你会退出帮派" |
| S6 | 换州时身上有脏钱 | 应结算/丢失规则明确（`[未知-服务端]`） |
| S7 | 好友筛选 | `realm_only_with_friends_toggle` 生效后，空结果要有空态 |
| S8 | 连续换州 | 应有冷却（`[未知]`），否则可刷"新州首杀" |

### 3.3 Sector/District：帮派争霸的棋盘

**玩法**：
- 区的 **Tier** 决定"能买到什么级别的物品"（`realm_info_tier_2_description` = "Access to level 2 items"，`vendor_tree_tooltip_condition_tier` = "Live in a lvl {0} settlement or higher"）
- 区的**归属**决定"谁收税、谁能进区中心"
- 区的**相邻关系**决定"能不能打过去"（`realm_conquest_sector_dialog_condition_3`）

**玩家能感知的区属性**：

| 属性 | UI 位置 | 说明 |
|---|---|---|
| 名称 | `district_name_*` / `MapDistrictNameView` | 10 个固定名 |
| Tier | `TierViewDescriptions`（3 档，ⅰ/ⅱ/ⅲ 图标） | 物资产出等级 |
| 归属帮派 | `MapObjectInfoOwnerView` / `ClanOwnerPanelView` | 有主/无主 |
| 区中心是否可进 | `sector_center_not_available_notification` = "Access is limited to district residents and members of the owning clan" | 只有居民/占领帮能进 |

**测试边界**：

| # | 场景 | 预期 |
|---|---|---|
| D1 | 住 1 区，想买 2 区的东西 | 拒绝并提示 `hints_can_buy_on_location` = "To purchase, you must live in a level {0} district or higher" |
| D2 | 非居民进区中心 | 拒绝（`sector_center_*`），队伍中一人不满足则整队不可进（`sector_center_not_available_for_party_members`） |
| D3 | 帮派占区后，原居民 | 仍可居住；区中心对"占领帮成员"新开 |
| D4 | 相邻区未控制时宣战 | 拒绝（`realm_conquest_sector_dialog_condition_3`） |
| D5 | 帮派军阶不足（Fighter） | 拒绝（`realm_conquest_sector_dialog_condition_2` = "Clan rank of Officer or higher"） |
| D6 | 非帮派成员 | 拒绝（`realm_conquest_sector_dialog_condition_1`） |
| D7 | 影子州长 | 只有控制 Highlands 的帮主可任（`realm_conquest_central_sector_dialog_description_4`） |

### 3.4 Settlement：可被买断的"公寓楼"

**玩法**：一个聚落有 **一个业主** + **N 个居民**。

| 角色 | 得到什么 | 付出什么 |
|---|---|---|
| 业主 | 收税、免费拿一块地、可驱逐、可建公共建筑 | 买断费、被抢时首当其冲 |
| 居民 | 有地可建、可用黑市、可租车 | 交税、被入侵 |

**三档聚落文案**（`【原作】`）：

- Tier1：`settlement_by_tier_1_description` = "A settlement on the outskirts. Take control of this settlement or occupy a plot in someone else's territory."
- Tier2：`settlement_by_tier_2_description` = "An advanced settlement. Purchase this settlement or occupy a plot in someone else's territory."
- Tier3：`settlement_by_tier_3_description` = "An elite settlement. Purchase this settlement or occupy a plot in someone else's territory."

**无主聚落不可进**（`【原作】`）= "You cannot enter an ownerless settlement."
→ **设计意图**：无主聚落是"待售资产"，不是"公共场所"。这避免了"没人管的聚落变成免费仓库"。`【推断】`

**测试边界**：

| # | 场景 | 预期 |
|---|---|---|
| ST1 | 进无主聚落 | 拒绝 + 文案 |
| ST2 | 业主自己进 | 允许，且看到 `settlement_owner_condition_label` = "You own this settlement" |
| ST3 | 队伍中有人无地 | `realm_need_full_party` = "All party members must be on the global map"（注意：这条讲的是"都在大地图"，与"无家"是两条不同校验） |
| ST4 | 聚落满员（无空地） | `region_user_settlement_limit_notification` = "There are no available plots in the settlement" |
| ST5 | 聚落改名 | 5 条命名校验全要触发（长度/纯数字/特殊符号/首尾空格/连续空格） |
| ST6 | 名字被占用 | `settlement_name_occupied_notification` = "Name already taken" |
| ST7 | 举报聚落名 | `settlement_name_report_modal_description` + 理由 `settlement_name_report_reason_abusive_name` |

### 3.5 Plot：玩家的家

**玩法**：玩家在聚落点阵里选一块地，**搬家时全部内容跟着走**（`rent_dialog_description` = "If you rent a new plot, you will move there and all contents of your base will be transferred"）。

**关键设计**（`【推断】`）：
- **只有 1 块地**（换租 = 整体搬家）→ 玩家不会"多房产收租"，避免地产模拟器化
- **地块不可被抢**（`realm_own_dialog_description_2` = "No one can take away purchased land"，这条是聚落主的权益文案，但地块本身也不在掠夺范围内）→ 个人财产安全感
- **搬家 = 内容整体迁移** → 等于一个"免费搬家"功能，降低换聚落成本

**测试边界**：

| # | 场景 | 预期 |
|---|---|---|
| P1 | 有地时再租一块 | 弹二次确认（`rent_dialog_title`），确认后整体迁移 |
| P2 | 新地块已被人占 | 不可选（点阵 UI 置灰） |
| P3 | 搬家时正在被入侵 | 应拒绝（`cant_move_plot_when_raid_lock_active` = "Cannot relocate under raid block. Wait for: {0}"） |
| P4 | 搬家时车里有货 | 车/货一并迁移（`[未知]` 需确认后备箱是否清空） |
| P5 | 租地券等级不符 | 拒绝（`codex_buy_plot_description` = "Your title's level must match the level of the district"） |
| P6 | 聚落无主时租地 | 拒绝（`plot_sale_*_description` = "You can only rent a plot in a settlement that has an owner."） |

### 3.6 Slot：32 种格子

详见 T06/D06。这里只给"世界架构"视角：
**槽位 = 世界的货币单位**。玩家的"富有程度"在系统里等价于"拥有多少可用槽位 × 每个槽位能放的最高级物品"。

## 4. 数值与节奏（三层时间轴）

`【推断，依据字段语义与既有文档】`

| 层 | 周期 | 系统 | 玩家一天要做的事 |
|---|---|---|---|
| 秒/分 | 5–120 s | 建造、破门、开箱、长按捡钱 | 在突袭里做实时决策 |
| 小时 | 1–24 h | 洗钱、税生效、贸易刷新、地块产出 | 上线 1–2 次：收钱、补货 |
| 天/周 | 24 h–7 d | 帮战排期、州寿命、联邦没收 | 每周打一次帮战、周末经历清算 |

**设计校验**：如果某个系统的周期落在"3–8 小时"这个尴尬区间，玩家会觉得"上线收一次不够，收两次浪费"。**所有产出周期应当 ≤12 小时的整数分之一**。`【推断】`

## 5. 与其他系统的耦合（世界架构是底座）

| 被耦合的系统 | 依赖的世界层 | 耦合点 |
|---|---|---|
| 建造 | Plot / Slot | 地块蓝图决定槽位集合 |
| 生产 | Settlement / Plot | 工作台放在地块/建筑槽里 |
| 经济 | Sector / Settlement | Tier 决定物价、物品等级 |
| PvP | Plot / Settlement | 突袭发生在聚落内的地块 |
| 社交 | Sector / Realm | 帮派占区、换州退帮 |
| 生存 | Settlement | 死后在急救柜/主屋复活 |
| 元系统 | Realm | 战令/成就是"州内"进度 |

## 6. 反作弊与边界情况

| 风险 | 设计防护 | 证据 |
|---|---|---|
| 卡地形进无主聚落 | 进入校验在服务端；客户端只显示 | `realm_notification_can_not_enter_without_owner` |
| 多次换州刷"新州第一" | 换州冷却 + 退帮 + 丢进度 | `switch_realm_*_warning` |
| 用"Fallback 区"当隐身区 | Fallback 是降级显示，不是可玩区 | `region_name_fallback` |
| 跨区好友互相刷税 | 税基是"同聚落洗钱流水"，跨区无效 | `tax_tooltip_description_1` |
| 一人多聚落当房东 | `OwnedSettlementConfig.MaxCount` 硬上限 | T01 §3 |
| 区主与帮主冲突 | 区主必须"帮派 Officer+"；影子州长必须"控制 Highlands 的帮主" | `realm_conquest_*_condition_*` |

## 7. 测试边界总结（本系统专属）

**必测的 12 条**：

1. 换区只在监狱生效
2. 换州 → 退帮 + 丢进度 + 二次确认
3. 满员州不可进，且"刚开的州"与"老州"提示不同
4. 无主聚落不可进
5. 无地块不可进任何聚落
6. 队伍中任一成员不满足条件 → 整队不可进
7. 聚落无名/重名/非法名 → 5 类校验分别触发
8. 租地券档位与区 Tier 不匹配 → 拒绝
9. 搬家时被突袭 → 拒绝并显示剩余锁时间
10. 区 Tier 不足 → 不可买高等级物品
11. 相邻区未控制 → 不可宣战
12. 影子州长只能由 Highlands 的帮主任命

## 8. 复刻时的三个"反直觉决定"

1. **无主聚落不可进** —— 直觉上"没人管的地方应该能进"，但这会让"买聚落"失去意义。**空间必须先有主，才可进入**。
2. **一人只有一块地** —— 直觉上"多买几块地收租"更像经营游戏，但那会让玩家变成房东而不是罪犯。**地块是"家"，不是"资产"**。
3. **换州要丢进度** —— 直觉上"换州应该保留资产"，但那样州寿命就失效了。**州是"赛季"，不是"频道"**。
