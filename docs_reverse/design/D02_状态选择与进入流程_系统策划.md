## 1. 这个界面的本质：**帮玩家选一台"现在值得进的服务器"**

玩家打开游戏时只有一个问题：**"我该进哪个州？"**

所以选州界面要同时回答四个子问题：

| 子问题 | 界面元素 | 判据 |
|---|---|---|
| 哪个州延迟低？ | 大区 + Ping | Region 切换 |
| 哪个州人多/人少？ | 占用档位（低/中/高/满） | `RealmOccupancy` + `SwitchRealmViewDescription` 阈值 |
| 哪个州刚开、我还能追上？ | `[New]` 标记 + 年龄 + "老州"警告 | `TimeRealmOldThreshold = 24h` |
| 我朋友在哪？ | 好友筛选 + 在线好友 tooltip | `SwitchRealmFriends*` |

**设计铁律**：这个界面**不允许**出现"我不知道该选哪个"的空白态。每台州至少要有"人口档 + 年龄"两个数字，否则玩家只能盲选。`【推断】`

## 2. 玩家旅程：从启动到落地的 7 步

| 步 | 玩家动作 | 系统反馈 | 玩家心里想 |
|---|---|---|---|
| 1 | 打开游戏 | 主菜单加载屏（`MainMenuLoadScreen`） | "快点" |
| 2 | 看到大区列表 | 亚洲/欧洲/北美 + Ping | "亚服 28ms，进这个" |
| 3 | 看到州列表 | 每行：ID、名字、人口档、年龄、[New]、好友 | "这个新的，人少，进" |
| 4 | 点开"开服时刻表" | 本周每天的开服时刻 | "下一台 3 小时后开" |
| 5 | 选中一台 | 高亮 + 确认按钮可点 | "就它了" |
| 6 | 确认换州 | 二次确认（退帮/丢进度/老州风险） | "我确定" |
| 7 | 载入 | 州加载屏（`RealmLoadScreen`） | "等" |
| 8 | 落点 | 上次位置/主屋/急救柜 | "我到家了" |

## 3. 数值设计（本机可读到的真值 + 推断值）

### 3.1 已解出的本地真值（`SwitchRealmViewDescription`，`【原作-实证】`）

| 参数 | 值 | 设计含义 |
|---|---|---|
| 老州阈值 | **24 小时** | 州开服 >1 天就提示"进度差距大" |
| 低占用阈值 | **20%** | <20% 显示"低" |
| 中占用阈值 | **82.5%** | ≥82.5% 显示"高"；100% 显示"满" |
| 推荐州数 | **3** | 列表最多标 3 个"Recommended" |
| 假人口 | **开，15,000** | 稀释真实人口，避免"空服劝退" |
| 好友昵称上限 | **10** | tooltip 最多列 10 人 |

### 3.2 推断的节奏参数（`【推断】`）

| 参数 | 建议 | 理由 |
|---|---|---|
| 州寿命 | 7 天 | 既有文档 + 周排期结构 |
| 列表刷新配额 | 30 次 / 小时 | 防刷 |
| 按 ID 搜索配额 | 10 次 / 小时 | 比刷新更贵（要查具体州） |
| 换州冷却 | 24 h | 防"打不过就换州" |
| 新州保护期 | 前 6 小时 | 避免老玩家进驻屠杀 |

## 4. 四个必须讲清的设计决策

### 4.1 为什么要"假人口 15,000"

**原作文案/配置**：`IsFakeRealmSizeEnabled = 1`、`FakeRealmSize = 15000`。

**意图**（`【推断】`）：
- 新州开服时真实人口可能只有几十人。如果UI 显示"12 人"，玩家会觉得"死服"，直接退出。
- 显示 15,000 让"这台州看起来正常"，而"满/高"的州反而会劝退。
- 这是**纯展示层**的运营手段：真实人数用于匹配/开新州判断，显示人数用于社交证明。

**风险**：玩家进服后看到大地图没人，会感觉被骗。**缓解**：新州前 24h 应该是"低人口 + 高活动"（NPC 密度、事件密度上调），让"人少"变成"资源多"而不是"没意思"。

### 4.2 为什么"老州"要警告但不禁止

- 老州 = 所有好地都被占了、物价高、帮派固化。
- 如果**禁止**进老州 → 玩家想找朋友玩就进不去。
- 如果**不警告** → 玩家进去发现没地，弃游。

**正确做法**（ROB RUN 的选择）：**允许进，但明确告知风险**，并给出替代（新州/推荐州）。`【推断】`

### 4.3 为什么换州要"退帮 + 丢进度"

这是**经济隔离**的必要条件：
- 如果换州能带走资产，玩家会在老州刷完资源去新州卖/用 → 新州经济被污染。
- 如果换州不退帮，帮派会变成"跨州组织" → 州内帮战失去意义。

**代价**：玩家换州的沉没成本极高 → **必须给"换州"一个强动机**（朋友、新州红利、老州已死）。`【推断】`

### 4.4 为什么换区只能在监狱

- 换区 = 换延迟 = 换整个社交圈。
- 如果随时能换，帮战/聚落战争可以"打不过就换区"。
- 限制在监狱 → 把"换区"变成**服刑期的一次战略选择**，且服刑本身有成本。`【推断】`

## 7. 测试边界（本系统专属 18 条）

**列表与状态**

1. 新州（<24h）不显示"老州"tooltip
2. 老州（>24h）显示 `RUN TIME` tooltip + 风险文案
3. 人口 19% → Low；21% → Medium；83% → High；100% → Full
4. 推荐州最多 3 个，且推荐逻辑不因刷新而抖动
5. 假人口开启时，真实人口 < 15,000 的州显示 15,000
6. 关闭假人口（改 SO）后显示真实值（回归验证）
7. 好友筛选开启后，无好友的州被过滤
8. 好友 tooltip 超过 10 人时显示 "And {0} others"

**搜索与刷新**

9. 输入 3 位数字 → `InputStringInvalidLength`
10. 输入合法格式但 ID ≤ 999 → `InvalidRealm`（"must be greater than 999"）
11. 输入非法区前缀 → `invalid_region`
12. 搜索冷却中 → `FindRealmByIdCooldown`
13. 刷新冷却中 → `RefreshRealmsCooldown`
14. 连续快速点刷新 → 按钮进入 loading 且不重复发请求

**切换**

15. 在野外点换区 → 拒绝（仅监狱）
16. 换州时在帮派 → 二次确认含"退帮"警告
17. 换州时全身资产 → 二次确认含"丢进度"警告
18. 满员州 → 确认按钮禁用 + 满员警告

**载入**

19. 载入中断线 → `NetworkIssuesView`，可重试
20. 服务端重启 → `ServerShutdownNotifications`（T16）
21. 载入中切后台 → 回来不重复结算（幂等）

## 8. 复刻时的三个"反直觉决定"

1. **假人口要保留** —— 看起来像欺骗，但它是解决"空服劝退"的标准手段；关键是**进服后有足够活动密度**兜底。
2. **换州要丢进度** —— 这会劝退一部分玩家，但它是经济隔离的唯一办法。**必须用"新州红利"补偿**。
3. **换区放监狱** —— 这个约束看起来很不方便，但它把"换区"从"菜单"变成"剧情"，值得保留。
