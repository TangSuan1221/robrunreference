## 1. 两个社交系统的分工

ROB RUN 把"社交"拆成两个**完全不同的东西**：

| | 队伍 Party | 帮派 Clan |
|---|---|---|
| 玩家感觉 | "我现在和谁一起玩" | "这块地归谁" |
| 本质 | 临时同步 | 永久产权 |
| 能不能一起打 | 能 | 帮战单独 |
| 有没有产权 | 没有 | 有 |

**为什么必须分开**：如果混在一起，会出现"帮派成员临时组队打自己帮派"的荒唐局面。**"一起玩"和"一起拥有"是两种关系**。`【推断】`

---

## 2. 玩家旅程：从"独狼"到"帮主"

| 阶段 | 玩家 | 系统 |
|---|---|---|
| 1 | 独狼 | 没有帮派，只能个人地块 |
| 2 | 加入帮派 | 获得帮派频道、帮派日志 |
| 3 | 参加帮战 | 帮派能占区/产业 |
| 4 | 升到 Officer | 能认领、能改开战时间 |
| 5 | 成为 Leader | 能转让、能改设置 |
| 6 | 控制 Highlands | 成为影子州长 |

**关键体验**：**"我从一个人变成一个组织的一部分"**。帮派不是"好友列表"，是"政治实体"。`【推断】`

## 3. 帮派的 4 阶与 11 权限

### 3.1 为什么是 4 阶

- **Leader**：1 人，最终决策
- **Officer**：少数，管理 + 参战
- **Fighter**：多数，参战
- **Recruit**：新人，只能看

**4 阶刚好**：3 阶太少（分不清"能管"和"能打"），5 阶太多（记不住）。

### 3.2 11 个权限位的设计逻辑

| 权限组 | 权限 | 设计意图 |
|---|---|---|
| **人事** | Invite / Kick / ChangeRanks / MakeLeader | 组织管理 |
| **信息** | PublishAnnouncement / ChangeSettings | 对外形象 |
| **战争** | Participate / KickFromBattle / PlaceBet / ChangeStartTime / CancelBets | 战争决策 |

**最关键的是"5 个战争权限分开"**：
- 能参战 ≠ 能踢人 ≠ 能下注 ≠ 能改时间 ≠ 能取消
- **战争决策被拆得很细**，因为"帮战"是帮派最核心的事件，不能一个人说了算。`【推断】`

### 3.3 同级不可互操作

**文案**：`set_rank_validation_notification` = "You cannot change the rank of a member with a rank equal to or higher than yours"

**为什么**：防内鬼。如果 Officer 能踢 Officer，帮派会天天政变。`【推断】`

## 4. 帮战：一场"预约赛"

### 4.1 流程

```
认领（Bet）→ 准备（Preparation）→ 战斗（Process）→ 结算（Completion）
```

**关键规则**：**死亡 = 退出 + 掉全部物品**。

**这条让帮战变成"高风险"**：
- 你不能"死了再来"
- 你带的东西可能全掉
- 所以帮战前要"轻装上阵"

`【实证+推断】`

### 4.2 帮战的三个限制

| 限制 | 原因 |
|---|---|
| **只允许平民** | 罪犯不能参加（防止"罪犯帮派"垄断） |
| **必须退队** | 防止"队伍+帮派"混编 |
| **人数上限** | 防"人海战术" |

### 4.3 帮战的收益

- 占区 → 收税
- 占产业 → 洗钱加成 + 现金奖励
- 帮派威望

## 5. 区主与州长：两级政治身份

### 5.1 区主（District Owner）

| 条件 | 说明 |
|---|---|
| 帮派成员 | 个人不行 |
| Officer+ | 军阶门槛 |
| **相邻区已被本帮控制** | **这是"地图推进"的核心** |

**收益**：收全区地主的税、控制全区、可进攻相邻区。

**"相邻区"条件是全游戏最重要的空间约束**：
- 帮派不能"空降"到任何区
- 必须**从已有的区向外扩张**
- 这让"地图"变成一张**真实的战争棋盘**

`【实证+推断】`

### 5.2 影子州长（Shadow Governor）

| 条件 | 说明 |
|---|---|
| 控制 Highlands | **唯一的中央区** |
| 是帮主 | 不是 Officer |
| — | 全州最高身份 |

**收益**：
- 统治所有犯罪组织
- 所有帮派都要交税
- 控制中央区

**Highlands 是"王座"**：
- 州末唯一能保资产的区（D01）
- 州长必须控制它
- 所以**所有顶级帮派都会争夺 Highlands**

`【实证+推断】`

## 6. 帮派的"史书"：日志系统

**日志类型**（`【实证】`）：
- 加入/离开/被踢
- 升阶/降阶
- 认领区/产业
- 帮战胜/败
- 成员家被入侵
- 捐款

**设计意图**：**帮派要有"记忆"**。新成员能看到"这个帮派打过哪些仗、谁贡献过"。这是"组织认同感"的来源。`【推断】`

## 9. 测试边界（本系统 22 条）

1. 建帮：币不足 → 拒绝
2. 建帮冷却中 → 拒绝
3. 入帮冷却中 → 拒绝
4. 成员满 → 拒绝
5. 申请超上限 → 拒绝
6. 申请过期 → 不可审批
7. 邀请过期 → 不可接受
8. 4 阶权限各自生效
9. 同级不可互操作
10. 帮主可转让
11. 帮战只允许平民
12. 帮战必须退队
13. 帮战人数上限
14. 帮战死亡 → 退出 + 掉全部
15. 区主需 Officer+
16. 区主需相邻区已被控制
17. 州长需控制 Highlands + 帮主
18. 帮派税在帮主聚落收
19. 换州 → 退帮
20. 帮派日志记录正确
21. 帮派可见性（Open/Request/Close）
22. 情报查询配额

## 10. 复刻时的三个"反直觉决定"

1. **队伍和帮派必须分开** —— 直觉上"一个社交系统就够了"，但"一起玩"和"一起拥有"是两种关系。
2. **区主必须相邻** —— 直觉上"谁强谁占"，但"相邻推进"让地图变成真实棋盘，避免空降。
3. **帮战死亡掉全部** —— 直觉上"帮战应该保护装备"，但"掉全部"让帮战变成"高风险决策"，而不是"随便打打"。
