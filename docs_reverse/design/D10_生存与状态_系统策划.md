# D10 · 生存与状态（系统策划）

> **对应技术文档**：`../tech/10_生存与状态_技术实现.md`
> **标记**：`【原作】` / `【推断】` / `【补全】`

---

## 1. 先破一个误区：这不是"生存游戏"

ROB RUN 没有饥饿、口渴、体温、疾病。它的"生存"是**社会性生存**：

| 传统生存 | ROB RUN |
|---|---|
| 饿死 | 被打死 |
| 渴死 | 被逮捕 |
| 冻死 | 被通缉追捕 |
| 病死 | 服刑（时间惩罚） |

**所以"生存系统"其实是"犯罪成本系统"**：

> 你犯罪 → 被通缉 → 被警察追 → 被抓 → 坐牢 → 出来继续。

这套循环的目的不是"活下去"，是**让犯罪有节奏、有代价、有戏剧性**。`【推断】`

---

## 2. 三条状态轴

```
生命轴：活着 ──被打死──> 死亡屏 ──复活──> 活着
通缉轴：清白 ──犯罪──> 通缉 ──被捕/被杀──> 入狱 / 洗白
服刑轴：自由 ──入狱──> 监狱 ──服刑完/越狱──> 自由
```

**三条轴独立但互相影响**：
- 通缉高 → 更容易被打死/被捕
- 被捕 → 进入服刑轴
- 服刑 → 出来时通缉清零（？）

---

## 3. 玩家旅程：一次犯罪的完整生命周期

| 步 | 玩家 | 系统 | 体验 |
|---|---|---|---|
| 1 | 在城里"变身罪犯" | 进入 Criminal 模式 | "我可以抢了" |
| 2 | 抢劫店铺/银行 | 通缉度上升 | "警察来了" |
| 3 | 被警察追 | 通缉 Buff、警笛 | "跑！" |
| 4 | 被打倒 | 倒地/击倒 | "别补刀" |
| 5 | 被抓 | 逮捕动画 + 扣押背包 | "我的货！" |
| 6 | 可以选择投降/贿赂 | `arrest_offer_bribe` | "花钱消灾？" |
| 7 | 入狱 | 指控流程 → 监狱 | "坐牢" |
| 8 | 服刑 | 年限倒计时 | "什么时候出去" |
| 9 | 越狱 / 服完 | 选择逃到哪个州 | "重新开始" |

**核心体验**：**"犯罪有代价，但代价是可控的"**。玩家能算出"这次抢劫值不值"。`【推断】`

## 4. 死亡：不是"惩罚"，是"结算"

### 4.1 死亡损失由"角色"决定（`【实证】`）

| 角色 | 死亡损失 |
|---|---|
| 平民 Civilian | **不掉**背包 |
| 警察 Police | **不掉**背包 |
| 罪犯 Criminal | **掉**背包 |

**设计意图**：
- 平民/警察不掉 → 鼓励"正常玩"
- 罪犯掉 → 让"犯罪"有真实风险

### 4.2 死亡屏的 4 个时间（`【实证】`）

| 时间 | 作用 |
|---|---|
| 复活冷却 | 防止"秒复活" |
| 软自动复活 | 给玩家一个"我不选就默认"的兜底 |
| 强制自动复活 | 防止玩家挂机卡在死亡屏 |
| 统一冷却 | 多个复活点共享冷却 |

**设计含义**：**死亡屏不是"结束"，是"选择"**。玩家要选"从哪复活"（主屋/附属/大地图/战场）。`【推断】`

### 4.3 复活点 = 急救柜（`【实证】`）

> `hints_first_aid_cabinet_description` = "You can install additional First Aid Cabinets at your base. Those will help you heal and **choose a respawn point** if you die in your settlement."

**这解释了急救柜的真正作用**：它不只是"回血"，它是**复活点**。所以"家里放几个急救柜"= "有几种复活选择"。`【推断】`

## 5. 通缉：按"杀谁"计分

`WantedPointsConfig` 的 8 个字段说明：

| 字段 | 设计意图 |
|---|---|
| `MaxPoints` | 通缉上限（到顶会怎样？） |
| `NpcKillPoints` | 杀 NPC 得分 |
| `PointsByKilledPlayersRoles` | **杀不同角色得分不同**（杀警察 > 杀平民？） |
| `KilledByCopSalaryReward` | 被警察击杀 → 警察有奖励 |
| `KilledByCopEquipCostPercentReward` | 被警察击杀 → 装备成本返还%（鼓励警察执法） |
| `ArrestRobberReward` | 逮捕罪犯 → 警察有奖励 |
| `ArrestRobberCharacterCostModifier` | 逮捕 → 角色成本修正 |

**核心设计**：**通缉不是"一个数字"，是"一组按行为定价的表"**。这让"犯罪"有精细的经济学。`【推断】`

## 6. 被捕与服刑：一段"叙事"而不是"传送"

### 6.1 被捕（`【实证】`）

```
arrest_progress = "Arresting..."          // 逮捕动画
arrest_offer_bribe = "Bribe {0}"          // 贿赂选项
arrested_time = "Can be released within:" // 释放倒计时
```

**三个选择**：
1. 等待释放（倒计时）
2. 贿赂（花钱）
3. 被押送监狱

### 6.2 入狱（`【实证】`）

- **两种入狱类型**：州寿命结束前 / 结束后（各自有年限）
- **指控流程**：文档 → 动画 → 信息 → 服刑
- **监狱里可以改名**（`NicknameValidationDescription`）

**设计含义**：**入狱不是"传送"，是一段"被审判"的流程**。玩家会感到"我真的被抓了"。`【推断】`

### 6.3 服刑年限是"跨州资产"（`【实证】`）

```csharp
UserImprisonmentYearsModel: RegionUserClientData + UserClientData
```

→ 年限既存在"州内"也存"跨州" → **换州后年限还在**。

**设计意图**：
- 年限不是"惩罚计时器"，是**身份/资历**
- `hints_imprisonment_years_description` = "Jail time is a direct reflection of your **authority** in the criminal world. Longer jail time unlocks various rewards, including **tattoos** that mark your achievements."

→ **坐牢越久，威望越高，解锁越多纹身**。这是"反向激励"：**犯罪不是为了逃避惩罚，是为了积累威望**。`【实证+推断】`

### 6.4 越狱 = 换州（`【实证】`）

> `hints_prison_escape_description` = "Use escape points to get back out into the world. **You can choose the most suitable state to escape to** from the list of available options."

→ **越狱是"换州"的合法入口**（与主菜单换州互补）。`【实证+推断】`

## 7. 州末联邦没收：赛季清算

**本地真值**（`【实证】`）：

| 参数 | 值 |
|---|---|
| `PopupCriticalTime` | 12 小时 |
| `FinalCountdownSeconds` | 10 秒 |
| `FinalMessageLeadSeconds` | 1 秒 |
| 弹窗时段 | 2 段（12h 起每 2h、3h 起每 1h） |
| 通知时段 | 5 段（12h/3h/1h/10min/1min） |

**流程**：
```
州剩余 12h → 开始弹窗（每 2h）
州剩余 3h → 加快（每 1h）
州剩余 1h → 通知（每 30min）
州剩余 10min → 通知（每 5min）
州剩余 1min → 通知（每 1min）
最后 10 秒 → 倒计时
```

**唯一豁免**：Highlands 居民（`confiscation_prison_escape`）。

**设计含义**：**赛季末是一场"强制结算"**，不是"服务端关服"。玩家有 12 小时准备。`【推断】`

## 10. 测试边界（本系统 26 条）

**死亡与复活**

1. 平民死亡 → 不掉背包
2. 警察死亡 → 不掉背包
3. 罪犯死亡 → 掉背包
4. 死亡屏显示击杀者昵称
5. 复活冷却中 → 按钮不可用
6. 软自动复活到点 → 默认点复活
7. 强制自动复活到点 → 必复活
8. 主屋急救柜复活 → 位置正确
9. 附属急救柜复活 → 位置正确
10. 大地图复活 → 位置正确
11. 投降后死亡 → `IsSurrenderedOnDeath` 生效

**通缉**

12. 杀 NPC → `NpcKillPoints`
13. 杀不同角色 → 不同分
14. 通缉到 `MaxPoints` → 封顶
15. 警察击杀/逮捕 → 获得奖励
16. 通缉 Buff 显示正确

**被捕与服刑**

17. 投降/被击倒 → 可被逮捕
18. 逮捕 → 背包扣押、装备保留
19. 贿赂 → 正确扣费
20. 释放倒计时 → 到点释放
21. 入狱前/后（州寿命）→ 年限不同
22. 指控流程 → 文档/动画/信息各步正确
23. 监狱改名 → 校验通过/拒绝
24. 越狱 → 可选目标州
25. 服刑年限跨州保留

**州末**

26. 12h/3h/1h/10min/1min 各档弹窗/通知正确
27. 最后 10 秒倒计时
28. Highlands 豁免

## 11. 复刻时的三个"反直觉决定"

1. **服刑年限是资产不是惩罚** —— 直觉上"坐牢越久越亏"，但 ROB RUN 把它变成"威望/纹身解锁"，让玩家**愿意坐牢**。
2. **死亡损失由角色决定** —— 直觉上"死亡都掉东西"，但"平民/警察不掉"保护了正常玩家。
3. **越狱是换州入口** —— 直觉上"越狱=逃跑"，但它其实是"重新开始"的合法路径，与主菜单换州互补。
