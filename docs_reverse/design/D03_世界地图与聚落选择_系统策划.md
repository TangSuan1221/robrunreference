# D03 · 世界地图与聚落选择（系统策划）

> **对应技术文档**：`../tech/03_世界地图与聚落选择_技术实现.md`
> **标记**：`【原作】` / `【推断】` / `【补全】`

---

## 1. 地图在这个游戏里的真实角色

它不是"导航工具"，而是**唯一一个"把产权、人口、危险、机会同时展示在一张图上"的界面**。

玩家打开地图想回答 4 个问题：

| 问题 | 地图上的答案 |
|---|---|
| "我家在哪？" | `PlayersPlot` / `PartyPlot` marker |
| "哪个聚落还有空地？" | `PlotSpot` / `PlotSpotInactive` marker + 人口计数 |
| "哪里在打仗？" | `ClanBattleFlagAttack/Defend` + `RealmBurnCells`（燃烧格） |
| "哪里能赚钱？" | `SettlementTaxPoint` / `CargoExchanger` / `BuyCargo` / `TraderNPC` |

**设计铁律**：地图上**任何 icon 都必须能点开同一个信息面板**（`MapObjectInfoPanelView`）。如果某个 icon 点了没反应，它就不该出现在地图上。`【推断】`

---

## 2. 三层地图 + 一张小地图

| 层 | 玩家用途 | 缩放 | 关键元素 |
|---|---|---|---|
| **州地图**（RealmGridView） | 看区、看归属、看聚落位置 | 固定俯视，格子化 | 区填充/道路/聚落/建筑/燃烧格 |
| **全屏地图**（MapDialog） | 找具体地点、放标记、看事件 | 3 级（0.33 / 0.66 / 1.0） | 79 种 marker + 信息面板 |
| **小地图**（Minimap） | 战斗中快速定位 | 固定 | 只显示高优先 marker |
| **地点内地图** | 在城里找店 | — | 店铺/警察局/医院等 |

---

## 3. 79 种 marker 的设计分层（这是本系统最值得抄的部分）

ROB RUN 不按"图标类型"分类，而按**"什么时候该被看见"**分三层：

### 3.1 第一层：全图常显（`VisibilityLevel = 0`，priority 90–100）

**只放 8 类**：
- 玩家自己（100）
- 队友 / 队友被抓 / 队友倒地（99/94/94）
- 罪犯（98）
- 警察（97）
- 平民（96）
- 任务点（95）
- 警报（95）
- 载具（94）/ 警车（93）

**设计意图**：这 8 类是"**我立刻要知道的**"。哪怕缩到最远，它们也在。`【推断】`

### 3.2 第二层：中景显示（`VisibilityLevel = 1`，priority 70）

店铺（咖啡/武器/装备/医院/酒店/珠宝/加油站/药房/电子店…）、小旅馆、停车场、码头/机库。

**设计意图**：这些是"**我决定去哪**"的信息，只有想找店时才需要。缩小到看全州时它们会消失，避免地图糊成一片。`【推断】`

### 3.3 第三层：近景显示（`VisibilityLevel = 2`，priority 50）

出生点（车/直升机）、警长点、制毒实验室、点击落点、仓库。

**设计意图**：这些是"**我到了才需要**"的信息。`【推断】`

### 3.4 优先级（priority）的排序逻辑

```
玩家(100) > 点击目标(100) > 队友(99) > 罪犯(98) > 警察(97) > 平民(96)
> 任务(95) = 警报(95) > 载具(94) > 警车(93) > 通缉星(90) > 求救(90)
> 帮战旗(80) > 聚落/产业(75) > 普通店铺(70) > 细节(50)
```

**关键**：**"玩家自己"永远 100，"别人的家"只有 70–75**。也就是说，地图在视觉上永远优先"人"而不是"建筑"。`【推断】`

## 4. 玩家旅程：从"进州"到"找到家"

| 步 | 玩家动作 | 地图反馈 | 验证点 |
|---|---|---|---|
| 1 | 进州，打开地图 | 州地图：10 个区、聚落点、自己位置 | 区名/区色/道路可见 |
| 2 | 缩放到中景 | 店铺 icon 出现 | `VisibilityLevel=1` 生效 |
| 3 | 点一个聚落 | 右侧面板：名称、业主、人口、税点状态 | `SettlementCardView` 字段齐全 |
| 4 | 发现"无主"聚落 | 卡片显示 "Bought out by the system" | `_empty` 状态 |
| 5 | 点"我的聚落" | 高亮自己的家，显示 `PlayersPlot` | marker 69 |
| 6 | 放一个自定义标记 | 地图上出现 `CustomMarker` | `map_add_marker` |
| 7 | 看到帮战旗 | 旗子 attack/defend 两种颜色 | `ClanBattleFlagAttack/Defend` |
| 8 | 看到燃烧格 | 该区被标红/燃烧 | `RealmBurnCellsView` |

## 5. 地图上必须能看出的 7 件事（UI 规格）

| # | 信息 | 载体 | 视觉规则 |
|---|---|---|---|
| 1 | 我在哪 | `Player` marker | 永远最上层、随朝向转 |
| 2 | 队友在哪 | `PartyMember` / `PartyCar` / `PartyPlot` | 队伍色、常显 |
| 3 | 我家在哪 | `PlayersPlot` | 只在近景、但自己总能找到 |
| 4 | 哪个聚落有主 | `SettlementCardView._active/_empty` | 有主=显示业主名+帮派；无主=显示"系统持有" |
| 5 | 哪个聚落能收税 | `SettlementTaxPoint` + `_taxPointState/_taxPointTime` | 税点可收时高亮 + 倒计时 |
| 6 | 哪里在打仗 | `ClanBattleFlag*` + `RealmBurnCells` | 旗 + 燃烧格双重表达 |
| 7 | 哪里有货/能卖 | `CargoExchanger` / `BuyCargo` / `TraderNPC` / `Lenny` | 交易类 icon |

## 6. 数值与参数（本机可读到）

`MapMarkerViewDescriptions`（`【原作-实证】`）：

| 参数 | 值 | 含义 |
|---|---|---|
| `VisibleRange` | **100.0** | marker 可见半径（世界单位） |
| `ShowHeightDiffRange` | **40.0** | 高低差箭头显示范围 |
| `HeightDiffTolerance` | **3.0** | 高低差容差（小于此值不显示箭头） |
| `SecondZoomLevel` | **0.33** | 第二级缩放 |
| `ThirdZoomLevel` | **0.66** | 第三级缩放 |
| `MinZoomMarkersScaleMultiplier` | **0.6** | 最小缩放时 marker 缩放 |
| `MaxZoomMarkersScaleMultiplier` | **1.1** | 最大缩放时 marker 缩放 |
| `MarkerSizeX/Y` | **55 × 55** | marker 基础像素尺寸 |
| `KeyboardMouseIconScaleOnBorder` | **0.7** | 出屏箭头（PC） |
| `TouchIconScaleOnBorder` | **0.8** | 出屏箭头（触屏） |
| `KeyboardDistrictNameScale` | **0.12** | 区名（PC 主图） |
| `KeyboardMinimapDistrictNameScale` | **0.7** | 区名（PC 小地图） |
| `DistrictNamePriority` | **60** | 区名优先级 |

## 8. 反作弊与边界情况

| 风险 | 防护 |
|---|---|
| 地图透视看到别人家内部 | 地图只显示"建筑外轮廓/图标"，不显示室内 |
| 标记刷屏 | 自定义标记数量应有上限（`[未知]`） |
| 用小地图定位敌人精确位置 | `CopCharacter`/`RobberCharacter` 只在特定条件显示（可见性规则在服务端） |
| 地图缩放卡顿 | 3 级缩放 + 虚拟滚动（`SliceScrollView`） |
| 出屏箭头误导 | `IsFarInRange` + `HeightDiffTolerance` 控制 |

## 9. 测试边界（本系统 16 条）

1. 三级缩放：0.33 / 0.66 / 1.0 各档的 marker 集合符合 `VisibilityLevel`
2. marker 重叠时按 priority 正确排序（玩家永远在上）
3. 玩家 marker 随朝向旋转（`IsTurning=1`）
4. 出屏目标显示边缘箭头（PC 0.7 / 触屏 0.8）
5. 高低差 > 3 时显示箭头，< 3 时不显示
6. 远距离 marker 淡出但不清除（`IsFadeAlpha`）
7. 小地图与主图的 marker 尺寸系数不同（0.5 vs 0.15 等）
8. 聚落卡片：有主/无主两种状态
9. 聚落卡片：税点可收/不可收 + 倒计时
10. 点击任何 marker 都能打开 `MapObjectInfoPanelView`
11. 无主聚落卡片显示 "Bought out by the system"
12. 目标面板折叠状态跨会话保持（PlayerPrefs）
13. 自定义标记可放/可删（`map_add_marker` / `map_clear_marker`）
14. 帮战旗 attack/defend 视觉区分
15. 燃烧格在帮战/突袭时出现，结束后消失
16. 地图上点击"无主聚落"→ 进入 → 被拒（文案正确）

## 10. 复刻时的三个"反直觉决定"

1. **marker 分三层，不是一层** —— 直觉上"所有 icon 都显示"最方便，但那会让地图在缩小时糊掉。**分层是地图可读性的唯一解**。
2. **"人"优先于"建筑"** —— 直觉上"我的家"最重要，但战斗时"谁在我附近"才是命。**priority 排序必须把角色放最上**。
3. **无主聚落也显示** —— 直觉上"没主的聚落没信息"，但它恰恰是"可购买"的入口，必须显示且要显示"系统持有"。
