## 1. 建造系统的本质：**"摆放"而不是"施工"**

玩家做的动作是：

> 从背包里拖一栋房子，放到地上的一个格子里。

不是：
> 点"建造"→ 等 30 秒进度条 → 房子出现。

**为什么这个区别重要**：

| 施工式 | 摆放式（ROB RUN） |
|---|---|
| 有时间成本，可以被打断 | 瞬时，不可被打断 |
| 有"建造队列"UI | 没有队列，只有背包 UI |
| 建筑完成前是"工地" | 建筑物品本身就是"房子" |
| 拆建筑要"拆除时间" | 拆建筑 = 放回背包 |

**摆放式的三个好处**（`【推断】`）：
1. 复用背包的全部拖拽逻辑（开发成本低）
2. 建筑可以随时被拿走放回背包（灵活）
3. 天然支持"建筑被撬开后变成掉落物"

## 2. 玩家旅程：从"空地"到"家"

| 步 | 玩家动作 | 系统反馈 | 时长目标 |
|---|---|---|---|
| 1 | 租到地 | 地图上出现地块轮廓 + 出租牌变"已租" | 即时 |
| 2 | 走到地块上 | 看到"建造台"（PlotUnlockBuilder） | — |
| 3 | 交互建造台 | 解锁建造面板，看到"主屋槽/围墙槽/附属槽" | 30 秒 |
| 4 | 放主屋（起始主屋是送的） | 主屋出现，内有 8 储物位 | 1 分钟 |
| 5 | 放围墙 | 围墙出现，地块边界清晰 | 1 分钟 |
| 6 | 放附属建筑 | 附属出现，可挂加密矿机/生产台 | 30 分钟 |
| 7 | 进主屋，放储物箱/货架/工作台 | 室内设施就位 | 1–2 小时 |
| 8 | 装满储物箱 | 家"有货"了 | 长期 |
| 9 | 被入侵 | 警报、防御块、Raid Lock | 之后 |

**关键体验**：**第 4 步必须"白送"**。如果玩家租到地后还要先买主屋，第一次体验会断在"我连个房子都没有"。ROB RUN 的做法：`PlotBuildingConfig.StartMainBuilding` 白送。`【实证+推断】`

## 3. 六道闸门 = 六条"你不能动"的理由

这是建造系统最值得抄的部分。玩家在建造面板里点一个槽，系统会依次问 6 个问题：

| 问题 | 玩家看到的 | 设计意图 |
|---|---|---|
| ① 这个物品能放这吗？ | 槽位变灰 | 基础类型校验 |
| ② 这槽刚动过吗？ | 冷却倒计时 | 防连点/防脚本 |
| ③ 家里有被撬开的箱子吗？ | "One or more broken objects prevent performing this action" | **防"被入侵时搬家"** |
| ④ 家里有没捡完的战利品吗？ | 同上 | **防"被入侵时清场"** |
| ⑤ 这一步需要确认吗？ | 二次确认弹窗 | 防误操作（如拆主屋） |
| ⑥ 现在在突袭锁里吗？ | "Cannot edit during raid block" | **防"被入侵时改布局"** |

**③④⑥ 是同一件事的三个面**：**让"被入侵"变成一段"你不能动"的时间窗**。

如果缺了这三道，玩家被入侵时的最优解永远是：
1. 收到警报 → 上线
2. 把所有东西塞进背包
3. 把建筑全拆了
4. 入侵者进来发现是空的

→ **整个 PvP 系统死亡**。`【推断】`

## 4. 改动配额：让"改布局"有成本

ROB RUN 有两块独立配额：

| 配额 | 管什么 | 恢复方式 |
|---|---|---|
| `ChangeBuildingExpiringResource` | 改建筑（主屋/附属/围墙） | 周期性 |
| `ChangeFurnitureExpiringResource` | 改家具（储物/货架/工作台/急救柜） | 周期性 |

**为什么需要**（`【推断】`）：
1. 防"被入侵前把家改成迷宫"（否则房主可以无限改布局拖时间）
2. 给"布局"这件事加决策重量（你不能随便试）
3. 商业化点（买配额）

**数值建议**（`【补全】`）：
- 建筑配额：上限 20，每 6 分钟回 1（满恢复 2 小时）
- 家具配额：上限 50，每 3 分钟回 1（满恢复 2.5 小时）
- 一次完整重建约消耗 8–15 个 → 玩家一周能重排 3–4 次而不焦虑

## 5. 地块蓝图：被低估的"空间设计"

`PlotSchemeDescription` 定义了：

| 元素 | 玩家感知 |
|---|---|
| 主屋槽/围墙槽/附属槽（2 个） | "我家能放 1 主屋 + 1 围墙 + 2 附属" |
| 5 组传送出点 | "我从家里出来不会卡墙" |
| 每类建筑的掉落点 | "我家被撬时东西掉在门外" |
| 建筑师桌 | "家里有个专门建造的桌子" |
| 出租牌位置 | "空地有牌子，点它租房" |
| `DiagonalSizeXZ` | "我家有多大" |

**关键洞察**：**"掉落点"是 PvP 体验的隐形设计**。如果东西掉在建筑内部，入侵者要"卡进废墟"才能捡；掉在门外，抢夺发生在开阔地，**更公平也更好看**。`【推断】`

### 5.1 地块等级（框架已留，内容未做）

`PlotGradeDescription` 有 `StartGrade` / `Grade3` 两档，每档带 `GridBorderSize` + `Scheme`。

**复刻建议**（`【补全】`）：
- 1 级地：小网格（4×4），只放主屋+围墙
- 2 级地：中网格（6×6），+2 附属
- 3 级地：大网格（8×8），+4 附属 + 更多工作台位
- **不同等级的地用不同蓝图**，让"高档区的地"看起来就不一样

## 6. 建造的三种"玩法流派"

| 流派 | 建造重点 | 弱点 |
|---|---|---|
| **生产型** | 开箱台/生产台/加密矿机/收集台 | 家当多 → 被抢损失大 |
| **防御型** | 防御块 + 模块 + 围墙 + 地堡 | 建造贵、不产出 |
| **隐蔽型** | 小房子 + 藏身点 + 少量储物 | 产出低 |

**设计目标**：让三种流派都有活路。当前 ROB RUN 的问题：**防御型的收益不明确**（防御只延长被撬时间，不阻止）。`【推断】`

## 7. 与其他系统的耦合

| 系统 | 耦合 |
|---|---|
| 产权 | 租地才能建；业主白送地 |
| 生产 | 工作台是生产设施（T07） |
| 经济 | 建筑/家具都要买（物品） |
| PvP | 建筑可被撬；掉落点在蓝图里定义 |
| 生存 | 急救柜 = 复活点 |
| 载具 | 车位/直升机位在建筑蓝图里 |
| 室内 | 7 种房间容器（卧室/厨房/厕所） |

## 9. 测试边界（本系统 30 条）

**解锁与蓝图**

1. 租地后未走到建造台 → 不能建
2. 走到建造台 → 面板出现，槽位数量与蓝图一致
3. 起始主屋/围墙/急救柜白送
4. 地块传送出点：角色/载具/建造台 各一组都能用
5. 建筑掉落点在门外（不在原地）

**六道闸门**

6. 放错类型 → 槽位变灰
7. 冷却中 → 不可操作 + 倒计时
8. 有被撬容器 → "One or more broken objects…"
9. 有散落战利品 → 同上
10. 拆主屋 → 二次确认
11. 突袭锁中 → "Cannot edit during raid block"
12. 突袭锁中搬家 → "Cannot relocate under raid block. Wait for: {0}"

**配额**

13. 建筑配额用尽 → 不可换建筑
14. 家具配额用尽 → 不可换家具
15. 配额按周期恢复（`PeriodDuration`/`Count`）
16. 两块配额互不影响

**交互**

17. 背包→槽、槽→背包、槽↔槽、槽↔背包 四条 RPC 都通
18. `CheckSpawnLootOnSwapBuilderWithInventory` 在会掉落时被调用
19. 清空槽（`BuilderUnsetMessage`）后物品回背包
20. 建造面板 12 种工厂各能打开（地块/主屋/附属/6 工作台/收集台/防御块）
21. 建造面板读取防御块状态（有/无）
22. 建造面板读取配额状态（剩余次数）

**失败与异常**

23. 缺物品放建筑 → 提示缺哪件
24. 建筑重置倒计时（`building_reset_notification`）显示正确
25. 断线重连后建造面板状态恢复
26. 两人同时改同一槽 → 服务端原子，后到者失败
27. 建筑被摧毁时，槽里的物品变掉落物（不是消失）
28. 主屋被拆 → 室内物品掉落
29. 围墙被拆 → `WallObbs` 碰撞消失
30. 地块等级切换（若启用）→ 蓝图/网格变化

## 10. 复刻时的三个"反直觉决定"

1. **建造是"摆放"不是"施工"** —— 没有进度条，看起来"太简单"，但它换来"随时可拆可搬"和"被撬变掉落"两个核心体验。
2. **改动配额要卡紧** —— 直觉上"让玩家自由改"更爽，但那会让 PvP 变成"房主无限改迷宫"。
3. **掉落点在门外** —— 直觉上"东西掉在原地"更自然，但门外掉落让抢夺更公平、更好看、更好捡。
