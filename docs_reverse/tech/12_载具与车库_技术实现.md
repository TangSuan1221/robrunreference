## 0. 一页结论

1. **载具是"物品"**：车/直升机都以 `InventoryItem` 形式存在，放回车库（Key Locker）才"召唤"到世界。
2. **购买载具要两个条件**：`CryptoCoinsPrice`（币）+ `ImprisonmentYearsRequired`（服刑年限门槛）→ **载具是"威望商品"**。
3. **车库是"槽位"**：`PlotCarSlotDescription`（车位，2 个）与 `PlotHelicopterSlotDescription`（直升机位，1 个 `Slot0`）。
4. **每辆车有 3 个独立的"改装区"**：引擎盖 / 底盘 / 后备箱（`CarUpgradesHolderTypeDescription`），**各自独立占用**。
5. **后备箱是"移动仓库"**：`CarTrunkDescription` 有 `InventoryCellsSizeDescription` + `CargoInventoryDescription` + `VehicleTrunkInventorySettingsDescription`。
6. **租车机制**：没车可以租，租的车"被自己的车顶掉"，后备箱东西掉在 Key Locker 前（文案实证）。

```csharp

public class GarageAddCarMessage : GarageVehicleInventoryMessage<PlotCarSlotDescription> {

    .ctor(int entityId, PlotCarSlotDescription first, PlotCarSlotDescription second);

// 203701
public class GarageSwapPlotCarWithInventoryMessage : GarageSwapPlotVehicleWithInventoryMessage<PlotCarSlotDescription> {
    .ctor(int entityId, PlotCarSlotDescription vehicleSlot, InventorySlotDescription fromInventorySlot, InventorySlotDescription toInventorySlot);

// 203859
public class GarageUnsetCarMessage : GarageUnsetVehicleMessage<PlotCarSlotDescription> {
    .ctor(int entityId, PlotCarSlotDescription slot);
}
```

`[实证]`

**5 条消息 = 车库的 5 个操作**：
| 消息 | 操作 |
|---|---|
| `GarageAddCar` | 把车（物品）放进车位 → **召唤到世界** |
| `GarageRemoveCar` | 把车从车位收进背包 |
| `GarageSwapCars` | 两个车位互换 |
| `GarageSwapPlotCarWithInventory` | 车位 ↔ 背包（指定位置） |
| `GarageUnsetCar` | 清空车位 |

**泛型设计**：`GarageVehicleInventoryMessage<T>` / `GarageSwapVehiclesMessage<T>` / `GarageUnsetVehicleMessage<T>` → **车与直升机共用同一套消息**，只是 `T` 不同。`[实证]`

## 4. Key Locker（钥匙柜）

**文案实证**（`[实证]`）：
```
hints_vehicle_keyholder_description = "To make a vehicle appear in the garage, you need to place the **keys** in an empty slot in the **Key Locker**. If the summoned vehicle was left outside the garage, you can return it by interacting with its garage spot."
hints_vehicle_keyholder_header = "Vehicle Selection"
hints_rent_vehicle_description = "If you don't have a personal vehicle, you can rent one at your base via the **Parking Terminal or Key Locker** at your base. The rented vehicle will be recalled once you get your own, and the contents of your trunk will be dropped on the ground."
rent_car_remove_and_clearing_description = "Party members will lose access to your rented vehicle. If you have any items stored in the trunk, they will be dropped in front of the Key Locker on your plot. If you do not have a land plot or the vehicle is not on your plot, the items from the trunk will be dropped on the ground!"
```

**Key Locker 规则**（`[实证]`）：
1. 把**钥匙**（key 物品）放进空槽 → 车出现
2. 车被留在外面 → 交互车位可以"召回"
3. **租的车**：一旦你有自己的车，租的车被收回，**后备箱东西掉在 Key Locker 前**
4. 如果没有地块/车不在自己地块上 → 东西掉在地上
