## 0. 一页结论

1. 地图不是一张"贴图"，而是 **6 套并行视图**：`RealmGridView`（州地图网格/区）、`MapView`（可缩放滚动的 2D 地图）、`MinimapView`（小地图）、`MapDialogView`（全屏地图弹窗）、`MapMarkerBehavior`（标记渲染）、`MapObjectInfoPanelView`（点选信息面板）。
2. **标记系统是本地可读的完整配置**：`MapMarkerViewDescriptions` §= **79 种 marker**，每种带 6 个数值（PC/触屏的缩放、小地图缩放、可见距离、优先级、是否远距淡出…）。本文件给出完整用法。
3. 地图支持 **3 级缩放**：`SecondZoomLevel = 0.33`、`ThirdZoomLevel = 0.66`；标记在缩放中按 `MinZoomMarkersScaleMultiplier=0.6 ~ MaxZoomMarkersScaleMultiplier=1.1` 缩放。
4. **聚落归属/人口/税点** 是三个独立的 marker 数据源，分别由 `RealmSectorSettlementsUpdater` / `RealmSectorUpdater` / `TaxPointMarkersUpdater` 驱动。
5. 地图点选后的右侧面板（`MapObjectInfoPanelView`）统一承载：标题/描述、所有者、保护者、交易加成、速度加成、现金加成、活动列表、奖励列表、建筑图标。

- `SecondZoomLevel = 0.33`
- `ThirdZoomLevel = 0.66`
- `MinZoomMarkersScaleMultiplier = 0.6`

### 4.2 渲染规则的实证（挑几个能说明设计意图的）

| marker | priority | VisibilityLevel | 特殊标记 | 含义 |
|---|---|---|---|---|
| `Player` | **100** | 0（总显示） | `IsTurning=1` | 永远最上层，且随朝向转 |
| `TapMarker` | **100** | 0 | `IsFar=1` | 点击目标点，最高层 |
| `PartyMember` | 99 | 0 | `IsTurning=0` | 队友常显 |
| `RobberCharacter` | 98 | 0 | `IsFar=1` | 罪犯在远处也显示 |
| `CopCharacter` | 97 | 0 | — | 警察 |
| `CitizenCharacter` | 96 | 0 | `IsTurning=1` | 平民 |
| `SecurityAlarm` | 95 | 0 | `IsFar=1, IsFarInRange=1, IsFadeAlpha=1` | 警报：远距也显示且淡出 |
| `Quest` | 95 | 0 | `IsFar=1` | 任务远距常显 |
| `PartyMemberArrested` / `Knockout` | 94 | 0 | `IsFar=1` | 队友被抓/倒地，高优 |
| `Car` / `PartyCar` / `Helicopter` / `PartyHelicopter` | 94 | 0 | `IsTurning=1` | 载具 |
| `CopCar` / `CopHelicopter` | 93 | 0 | `IsTurning=1` | 警车 |
| `StarMarkerModel` | 90 | 0 | `IsFar=1, IsFadeAlpha=1` | 星级/通缉 |
| `Call` | 90 | 0 | `IsFar=1, IsFarInRange=1` | 呼叫/求救 |
| `ClanBattleFlagAttack/Defend` | 80 | 0 | `IsFadeAlpha=1` | 帮战旗，最重要但低于本人 |
| `Cafe`/`Police`/… | 70 | **1（中景才显示）** | — | 普通店铺 |
| `SpawnCar` / `SpawnHelicopter` / `Sherif` / `MethLab` / `TapMarker` | 50 | **2（近景才显示）** | `IsFadeAlpha=1` | 细节 marker |

**→ 三条可复用的规则**（`[推断]`）：
1. **"玩家自己"永远 priority=100**，排在一切之上；其次队友、其次敌人、其次设施。
2. **`VisibilityLevel` 是三级**：0=全图可见、1=中/近景、2=仅近景。这实现"缩小时地图干净、放大时信息丰富"。
3. **`IsFar + IsFadeAlpha`** 组合做"远距离仍可见但变淡"（关键信息不丢，但不干扰）。

## 8. 小地图（`MinimapView`）

`MinimapView`（dump.cs:288982）+ marker 的 `*MinimapScale` 字段 → **小地图是独立的一套缩放系数**，不是主地图等比缩小。`[实证]`

例：`Player` 在小地图是 0.5，在 PC 主图是 0.15；`PlotSpot` 在小地图是 0.8，主图是 0.3。→ **小地图上"点"要大，主图上"面"要准**。`[推断]`
