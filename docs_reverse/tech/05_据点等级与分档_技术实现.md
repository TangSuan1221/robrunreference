## 0. 一页结论

1. "据点等级"其实是 **三个不同的东西叠在一起**，必须分开：
   - **District Tier（区档）**：Tier 1/2/3，是"区的等级"，决定物价、物品等级、税率、洗钱速度、帮战门槛
   - **Settlement 无等级**：聚落本身没有等级字段；它的"等级感"来自**所在区 Tier**
   - **RealmVersion（赛季版本）**：整套世界参数的版本号，目前构建里**只有 V0**
2. **Tier 是 `TierParams` 这个"经济参数包"的索引**，不是简单的"难度系数"。一个 Tier 同时定义：价格表、税率、洗钱速度、帮战下限、每区聚落数、是否可买聚落。
3. **当前构建只解出 `RealmVersions.V0`**（`RealmVersions` 静态类只有一个 `V0` 字段 + `Last` 属性）——也就是说，"版本化"是**框架已就绪、内容未启用**。
4. **区档通过 `TierDescriptionExtensions.GetParams(tier, realmVersion)` 取**；取不到 → `TryGetParams` 返回 false → 该区/该档不可用。
5. **玩家的"等级感"来自 3 条硬门槛**：住哪档区（决定能买什么）、地券档位（决定能租哪档）、物品档位（决定能买到什么）。

## 1. 三个"等级"概念的正名

| 概念 | 类型 | 取值 | 谁定义 | 决定什么 |
|---|---|---|---|---|
| **Tier**（区档） | `TierDescription : MyEnumItem` | `Tier1` / `Tier2` / `Tier3` | `TierDescriptions`（静态枚举） | 一切经济参数（见 §2） |
| **District/Sector**（区） | `SectorDescription : MyEnumItem` | `Sector0..Sector9` | `SectorDescriptions`（10 个） | 区名、邻接、所属聚落、所属建筑 |
| **RealmVersion**（版本） | `RealmVersion` struct | `V0`（当前唯一） | `RealmVersions` | 整套世界参数的版本 |

## 2. `TierParams`：一个 Tier 到底定义了什么（dump.cs:80017）

```csharp
public class TierParams {
    // 开关
    public bool IsEnabled;
    public bool CanBuySettlement;
    // 规模
    public int SectorSettlementsCount;
    public int ClanBattleBetMinAmount;
    // 经济乘区
    public float LaunderingDirtyCashPerPeriodModifier;
    // 税率
    public float SettlementWithoutOwnerTax;
    public float SettlementWithOwnerTax;
    public float SettlementPurchaseTax;
    public float SectorWithOwnerTax;
    public int SettlementOwnerTaxBonusFrom;
    public int SettlementOwnerTaxBonusTo;
    // 5 张价格表
    public InventoryItemsPriceDescription PlotPrice;
    public InventoryItemsPriceDescription SettlementPrice;
    public InventoryItemsPriceDescription BuildingPriceForSettlement;
    public InventoryItemsPriceDescription BuildingPriceForPlot;
    public InventoryItemsPriceDescription LocalMovePlotPrice;
}
```

`[实证]`

**这张表的 7 个功能块**：

| 功能块 | 字段 | 玩家感知 |
|---|---|---|
| 开关 | `IsEnabled` / `CanBuySettlement` | "这个区能不能进 / 能不能买" |
| 规模 | `SectorSettlementsCount` | "这个区有几个聚落" |
| 帮战 | `ClanBattleBetMinAmount` | "打这个区要押多少" |
| 洗钱 | `LaunderingDirtyCashPerPeriodModifier` | "这个区洗钱快不快" |
| 税 | 4 个 tax + 2 个 bonus 区间 | "这个区抽多少税" |
| 价格 | 5 张价格表 | "买地/买聚落多少钱（物品）" |
| 物品等级 | **不在此表**——由 `SectorParams`/`InventoryItem` 侧的 tier 门槛实现 | "能买几级物品" |

### 2.1 `SettlementOwnerTaxBonusFrom/To`：税率奖励区间（`[实证+推断]`）

两个 int 字段名明确：**业主税率奖励的"起止"**。推断语义：
- 业主实际税率 = `SettlementWithOwnerTax` 的基础上，根据某些条件（居民数？聚落建筑？）在 `[From, To]` 区间内浮动。
- `SettlementBonusExtensions.TryGetSettlementDefensePointsBonus(...)` 证明"聚落建筑可以改税率/防御"。

### 2.2 `TierExtensions.CheckTierRequirement(actual, required)`（`[实证]` dump.cs:8917）

```csharp
public static bool CheckTierRequirement(TierDescription actual, TierDescription required);
```

→ **"玩家住在 Tier X 区"与"某物品要求 Tier Y"的比较**。这是所有"等级门槛"的**唯一比较函数**。`[实证+推断]`

**文案对应**：
- `hints_can_buy_on_location` = "To purchase, you must live in a level {0} district or higher"
- `vendor_tree_tooltip_condition_tier` = "Live in a lvl {0} settlement or higher"
- `laptopb_tier_1_title` = "LEVEL 1 ITEMS" / `laptopb_tier_2_title` = "LEVEL 2 ITEMS" / `laptopb_tier_3_title` = "LEVEL 3 ITEMS"

## 3. RealmVersion：框架就绪、内容未启用

### 3.1 结构（`[实证]`）

```csharp
// dump.cs:161511
public struct RealmVersion : IComparable<RealmVersion>, IEquatable<RealmVersion> {
    public const int EmptyRaw = -1;
    public const int MinRaw = -1;
    public const int MaxRaw = int.MaxValue;
    public static readonly RealmVersion Empty, Min, Max;
    public int Value { get; }
    public .ctor(int value);
    // 全套比较运算符 + ToString

// dump.cs:31051
public static class RealmVersions {
    public static readonly RealmVersion V0;
    public static RealmVersion Last { get; }
}
```

→ **当前构建只有一个版本 `V0`**。`Last` 指向 V0。`[实证]`

### 3.2 版本化的三类配置

| 配置 | 版本化方式 | 证据 |
|---|---|---|
| 地图参数 | `RealmMapComputedConfig._versionConfigs : RealmVersionedValues<RealmVersionedValue<RealmMapVersionComputedConfig>>` | dump.cs:79193 |
| 区邻接 | `SectorNeighboursRealmVersion0` / `SectorNeighboursRealmVersion1` | dump.cs:30956 / 30965 |
| 区集合 | `SectorsRealmVersion0` / `SectorsRealmVersion1` | dump.cs:30974 / 30983 |
| 聚落建筑 | `SettlementBuildingsRealmVersion0` / `SettlementBuildingsRealmVersion1` | dump.cs:31015 / 31024 |
| 档位 | `TiersRealmVersion0` / `TiersRealmVersion1` | dump.cs:31033 / 31042 |
| 州参数 | `RealmParamsRealmVersion0` | dump.cs:30947 |
| 地图预制 | `RealmGridViewDescription._realmVersion` | dump.cs:1767594 |

`[实证：类存在]`

**关键**：虽然 `RealmVersions` 只有 V0，但**每个版本化配置类都同时有 `RealmVersion0` 和 `RealmVersion1` 两套**。这意味着：
- **资产已为 V1 准备好**（类存在）→ V1 是"内容已规划、尚未启用"
- 当前 `StaticReferences` 下发的可能只有 V0 的数据 → V1 类在运行时可能是空/未注册

`[推断]`

## 4. "等级"在 5 个系统里的具体作用

### 4.1 能买什么（物品等级门槛）

- 数据：`laptopb_tier_1/2/3_title` = "LEVEL 1/2/3 ITEMS"
- 判定：`TierExtensions.CheckTierRequirement(playerTier, itemTier)`
- 文案：`hints_can_buy_on_location` / `vendor_tree_tooltip_condition_tier`

### 4.2 能租哪档地（地券档位）

- `plot_sale_1/2/3_description`：Tier 1/2/3 地券分别对应"level 1/2/3 district"
- `codex_buy_plot_description` = "Your title's level must match the level of the district"

### 4.3 能买哪个聚落（区开关）

- `TierParams.CanBuySettlement`（`[未知值]`）
- `settlement_by_tier_1/2/3_description` 三档文案

### 4.4 税率与洗钱速度

- `SettlementWithoutOwnerTax` / `SettlementWithOwnerTax` / `SettlementPurchaseTax` / `SectorWithOwnerTax`
- `LaunderingDirtyCashPerPeriodModifier`
- `SettlementOwnerTaxBonusFrom/To`

### 4.5 帮战门槛

- `ClanBattleBetMinAmount`
- `TierDescription` 出现在 `ClanBattleTierDescription`（帮战分档）中

## 6. 数据流：玩家"当前等级"是怎么被算出来的

```
玩家所在聚落 → SettlementDescription
     → 该聚落的 Sector（SectorParams.Locations 反查）
        → SectorParams.TierFunc()
           → TierDescription
              → TierDescriptionExtensions.GetParams(tier, realmVersion)
                 → TierParams（当前档的全部参数）
```

`[实证：API 存在；推断：调用链]`

**这就是为什么"住哪"决定"能买什么"**：玩家的 Tier 不是账号属性，而是**由住址推导出来的**。搬家 = 换等级。`[推断]`
