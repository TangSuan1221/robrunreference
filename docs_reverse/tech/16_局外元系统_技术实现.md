## 0. 一页结论

1. **教程是一条 15 步的固定链**（`TutorialStepDescription`），按"监狱 → Hub → 城市 → Hub"四个场景段组织，每步带 `IsPrisonStep/IsHubStep/IsCityStep` 标签。
2. **Codex（图鉴）是"强制阅读"的**：`CodexViewDescription.IsMandatory` —— 有些页必须看完才能继续。
3. **战令（BattlePass）是"奖励分页"结构**：`BattlePassRewardId` + `BattlePassRewardView` + 多页 rewards。
4. **全局通知是"分层"的**：`GlobalNotificationDescription`（模板）+ `ClientNotification`（客户端通知）+ `GlobalNotificationModel`（运行时）。
5. **维护/停服有专门的屏**：`MaintenanceScreenModel` + `ServerShutdownNotifications`。
6. **改名有统一校验**：`NicknameValidationDescription`（聚落名/玩家名/帮派名共用一套规则）。

**完整教程链**（`[实证]`）：

```
[监狱] 纹身对话 → 纹身 → 越狱对话 → 越狱
   ↓
[Hub] 开场对话 → 租车 → 上车 → 离开 Hub
   ↓
[城市] 进入 → 变身罪犯 → 首次抢劫 → 离开城市
   ↓
[Hub] 结束对话 → Finished
```

**关键**：**教程从"监狱"开始**——玩家一进游戏就在坐牢，然后越狱。这是"叙事化教程"的典型设计。`[实证+推断]`

## 11. 与"局外系统"的耦合

| 元系统 | 耦合 |
|---|---|
| 教程 | 强制走"租地→建房→洗钱"（D01 旅程） |
| Codex | 记录所有物品/机制（含据点建筑/槽位） |
| 战令 | 奖励包含 Land Plot Title / Settlement Title |
| 邮件 | 通知"你家被入侵"、"税可收" |
| 通知 | 基地警报、新解锁 |
| 维护 | 停服前通知 |
| 举报 | 聚落名/玩家名 |
