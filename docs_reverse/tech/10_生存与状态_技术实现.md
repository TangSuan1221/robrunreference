## 0. 一页结论

1. **局外"生存"不是饥饿/口渴**，而是**三条独立的状态轴**：**生命（死亡）**、**通缉（Wanted）**、**服刑（Imprisonment）**。
2. **死亡有完整的"屏幕模型"**：`DeathScreenModel` 含 4 个时间戳（冷却、软自动复活、强制自动复活）+ 多种复活按钮 + 击杀者信息。
3. **复活是 5 种命令**：`RespawnCommand` / `RespawnOnGlobalMapCommand` / `SpawnAtTargetBattleCommand` / `SpawnByMainBuildingCommand` / `SpawnByOutBuildingCommand`（+ `ReviveWithCopPresetCommand`）。
4. **通缉点是"按角色击杀"计分**：`WantedPointsConfig.PointsByKilledPlayersRoles`（杀不同角色得分不同），且有警察专属奖励。
5. **服刑年限是"跨州资产"**：`ImprisonmentYearsByDataModel` 从 `RegionUserClientData` / `UserClientData` 读，`PrisonEnterTypeDescription` 分"州寿命结束前/后"两种入狱类型。
6. **越狱点是地点配置**：`LocationPrisonEscapeDescription` 每个越狱点有 `EntityId` + 交互点 + 忽略的物理体。

## 1. 三条状态轴

| 轴 | 数据 | 触发 | 后果 |
|---|---|---|---|
| **生命** | `DeathScreenModel` | 被打死 / 被打晕后被杀 | 掉背包（视角色）/ 复活 |

## 2. 死亡（`DeathScreenModel`，dump.cs:383737）

```csharp
public class DeathScreenModel : ScreenModel {
    public DeathType Type;

    public bool NeedClientAutoRespawnMessage;
```

`[实证]`

### 2.1 死亡界面的 4 个时间

| 时间 | 语义 |
|---|---|
| `CooldownEndTs` | 复活按钮何时可用 |
| `SoftAutoRespawnTs` | "软"自动复活（可能可打断/可选位置） |
| `ForceAutoRespawnTs` | "强制"自动复活（到点必走） |
| `WithUnitedCooldown` | 是否与其他冷却统一 |

**推断流程**（`[推断]`）：
```
死亡 → 死亡屏（显示击杀者）
  → 等待 CooldownEndTs（复活按钮亮起）
  → 玩家选复活点（Buttons[]）
  → 或到 SoftAutoRespawnTs 自动走默认点
  → 或到 ForceAutoRespawnTs 强制复活
```

## 3. 复活：5+1 种命令（`[实证]`）

```csharp
// dump.cs:407533
public abstract class ReviveCommand : INetworkCommand { }
// 子类
public class RespawnCommand : ReviveCommand { }                          // 普通复活
public class RespawnOnGlobalMapCommand : ReviveCommand { }               // 复活到大地图
public class SpawnAtTargetBattleCommand : ReviveCommand { }              // 复活到目标战斗
public class SpawnByMainBuildingCommand : ReviveCommand {                // 主屋复活
    FirstAidCabinetSlotDescription FirstAidCabinetSlot;
}
public class SpawnByOutBuildingCommand : ReviveCommand {                 // 附属复活
    OutbuildingSlotDescription OutbuildingSlot;
    FirstAidCabinetSlotDescription FirstAidCabinetSlot;
}
public class ReviveWithCopPresetCommand : ReviveCommand { }              // 以警察身份复活
```

`[实证]`

**关键**：
- **复活点由"急救柜槽位"决定**（`FirstAidCabinetSlot`）——这就是为什么"急救柜"是生存系统的一部分（`hints_first_aid_cabinet_description` = "You can install additional First Aid Cabinets at your base. Those will help you heal and **choose a respawn point** if you die in your settlement."）
- **主屋与附属各有急救柜**，所以 `SpawnByMainBuildingCommand` / `SpawnByOutBuildingCommand` 是两个不同的复活点

## 6. 通缉（`WantedPointsConfig`，dump.cs:70671）

```csharp
public class WantedPointsConfig {
    int MaxPoints;                                          // 通缉点上限
    int NpcKillPoints;                                      // 杀 NPC 得分
    IReadOnlyDictionary<PlayerRoleDescription, int> PointsByKilledPlayersRoles;  // 杀不同角色得分
    int KilledByCopSalaryReward;                            // 被警察击杀的警察奖励
    float KilledByCopEquipCostPercentReward;                // 被警察击杀的装备成本返还%
    int ArrestRobberReward;                                 // 逮捕罪犯的警察奖励

```

`[实证]`

**设计含义**（`[推断]`）：
- **通缉按"杀了谁"计分**：杀警察 vs 杀平民 vs 杀罪犯，得分不同
- **警察有正向激励**：击杀/逮捕罪犯都有奖励
- **"被警察击杀"也有奖励** → 鼓励"对抗警察"？

## 8. 州末联邦没收（`ConfiscationDescription`，dump.cs:413319）

```csharp
public class ConfiscationDescription : ScriptableObject {
    ConfiscationPopupTime[] PopupTime;      // 弹窗时段表
    int PopupCriticalTime;                  // 弹窗临界点
    ConfiscationPopupTime[] NotificationTime;  // 通知时段表
    int FinalCountdownSeconds;              // 最终倒计时
    int FinalMessageLeadSeconds;            // 终局提示提前量
}
public class ConfiscationRule {
    public static bool IsActiveByInterval(ConfiscationPopupTime[] timeRanges, long leftTime, long lastShowedInterval);
    public static ValueTuple<bool,long> CheckActiveByPosition(ConfiscationPopupTime[] timeRanges, long leftTime, long lastShowedLeftTime);
}
public class ConfiscationModel {
    PlayerPrefsModel _playerPrefsModel;
    bool CanShowPopup;
    long GetLastShowPopupTime / GetLastShowNotificationTime;
    int LastRealmId;
    void SetSkipConfiscationPopup(bool skip);
}
```

`[实证]`

**本地真值**（既有文档已读出，本文件确认字段结构）：
- `PopupCriticalTime = 43,200,000`（12h）
- `FinalCountdownSeconds = 10`
- `FinalMessageLeadSeconds = 1`
- `PopupTime` 2 段 / `NotificationTime` 5 段

**`ConfiscationModel` 用 PlayerPrefs 记"上次弹窗时间"** → **弹窗频率在客户端控制**（防重复弹）。`[实证+推断]`
