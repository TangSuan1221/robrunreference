## 0. 一页结论

ROB RUN 用**三层锁**解决多人交互，每层解决不同问题：

```
L1 角色级互斥    每个玩家同时只能做一件事（32 种互斥进程）
L2 共享打开态    多人可同时开同一个箱子（引用计数）
L3 独占占用      同一个物体只能一个人（单值槽位）
```

**四类冲突对应四种解法**（不能用一个方案打四个问题）：

| 类 | 场景 | 解法 |
|---|---|---|
| C1 同物体·同功能 | 两人开同一储物箱 | **L2 共享** + 引用计数 |
| C2 同物体·不同功能 | 开引擎盖 vs 开后备箱 | **L3 分区**（一车 3 个独立锁位） |
| C3 同物体·互斥功能 | 两人藏进同一衣柜 | **L3 独占** + "Cover occupied" |
| C4 同玩家·互斥动作 | 不能同时撬锁和捡钱 | **L1 角色锁** |

## 1. 三层锁（精确字段）

### L1 角色级互斥（`[实证]` dump.cs:162109 / 65127）

```csharp
public abstract class CommonProlongedInteractionHandlerModel {
    public abstract MutuallyExclusiveProcessesDescription Process { get; }
    internal abstract UseEntityCommandDescription StartCommand { get; }
    internal abstract UseEntityCommandDescription StopCommand { get; }
    // ...
}
// 32 种互斥进程（dump.cs:65127）
```

→ **一个玩家同一时刻只能属于一个 `Process`**。

### L2 共享打开态（`[实证]` dump.cs:174892）

```csharp
public class InteractableObjectOpenedModel {
    private readonly IPrimitiveData<bool> _data;          // 服务端同步
    private readonly HashSet<int> _interactingCharacters; // 谁在交互（客户端）
    public bool IsOpened { get; }
    public void AddInteractingCharacter(int entityId);
    public void RemoveInteractingCharacter(int entityId);
    private void UpdateOpenedState();
}
```

→ `IsOpened = #characters > 0`。A 走 B 还在 → 不关。

### L3 独占占用（`[实证]` dump.cs:176027）

```csharp
public class HideObjectModel {
    private const int _emptyEntityId = -1;
    private int _entityId;
    public bool IsEmpty => _entityId == _emptyEntityId;
    public void Set(int entityId);
}
```

→ 单值槽位，写入即占用。

## 2. 与"局外系统"的接口

| 局外系统 | 用哪层 | 例子 |
|---|---|---|
| 建造 | L3 + 六道闸门 | 槽位只能一个人改 |
| 工作台 | L2 + L1 | 多人可同时看，但操作是 L1 |
| 储物箱 | L2 | 共享打开 |
| 载具改装 | L3 分区 | 3 个区各自独立 |
| 藏身点 | L3 | 独占 |
| 交易商 | L3 + 排队 | "Wait until the seller is free" |
| 现金堆 | **L1 + 扣减式** | `TakeCash(amount)`，不锁物体 |
| 撬门/防御块 | L1 + 进度共享 | 第二人**加速**而非被拒 |
| 警用装备柜 | 逐件 L3 | "In Use" / "Free" |

## 3. 三条"反直觉定案"（引自既有规格）

1. **抢钱绝不锁物体** —— `CashLootNodeModel.TakeCash(int amount)` 是扣减式。两人同抢 800 应得 500+300，而不是赢者通吃。
2. **撬门允许协力加速** —— 进度是**物件级**的，`totalBreaching = Σ 所有撬门者的 Breaching 值`。
3. **读操作零 RPC** —— L2 类（大部分基地交互）不发任何服务端消息。

---

## 4. 两个必须做对的技术点（引自既有规格）

- **断线清理**：`SessionOccupancyRegistry` 按 sessionId 索引全部占用，断线时批量释放。
- **外力清扫**：独占锁必须有"持有者被外力清除"的路径（`HideObjectRules.ExtractCharacterOutOfHideObject`）。
