## 0. 一页结论

1. **黑市 = 一台笔记本电脑（Laptop）**，有 **3 个页签**（Construction / Gear / Vehicles）+ **两级筛选**（Filter / SubFilter）+ **Tier 分组**。
2. **Shipments（VendorTree）是一棵"解锁树"**：节点是物品，解锁要"币 + 前置节点 + 生活区等级（Tier）+ 服刑年限"。
3. **价格/出售有三个乘区**（`BuyerRules`）：`playerModifier`（玩家） × `battleModifier`（地点/战斗） → `bonusModifier` → 现金。
4. **CargoExchanger（Smuggler's Van）是一个"队列式"交易点**：`MaxCashAmount` / `MaxCargoAmount` / `MaxPutCargoQueueLength`。
5. **Barter（以物易物）是"配方"制**：`BarterRecipeDescription` = 一组输入物品 + 1 个产出。
6. **交易范围硬编码 `TradeDistance = 3`**（平方距离 9）—— 超过这个距离不能交易。

## 4. 出售（Buyer / Fence / Smuggler）

### 4.1 `BuyerRules`（dump.cs:188949）—— 售价公式

```csharp
public static class BuyerRules {
    public static bool CanInteractWithBuyerBySector(SectorDescription locationSector, SectorDescription playerSelfSector);
    public static float GetPlayerSellAdditiveModifier(BattleCharacterModel battleCharacter);
    public static float GetLocationSellAdditiveModifier(SectorDescription sectorDescription, LocationDescription location, RealmVersion realmVersion);
    public static void CalculateCashAmounts(int amount, float playerModifier, float battleModifier,
        out float bonusModifier, out int bonusCashAmount, out int totalCashAmount);
    public static float GetBonusModifier(float playerModifier, float battleModifier);
    public static int GetCashAmountByModifier(int amount, float modifier);
    public static bool CanMoveItemToBuyerInventory(InventoryItemDescription item);
}
```

`[实证]`

**售价公式**（`[推断，依据方法名]`）：

```
bonusModifier  = playerModifier + battleModifier      （加法叠加）
bonusCash      = amount × bonusModifier
totalCash      = amount + bonusCash
```

**两个乘区**：
- `playerModifier`：玩家侧（恶名/声望？）
- `battleModifier`：地点侧（区/modifier `SectorParams.BuyerSectorModifier`？）

**关键限制**：`CanInteractWithBuyerBySector` —— **只能在"自己的区"或指定区卖**（对应 `sector_center_buyer_is_unavailable_for_players_who_dont_live_in_the_sector` = "Trading available only to district residents"）。

`[实证]`

**"队列式"设计**（`[实证+推断]`）：
- 投货不是立刻换钱，而是**进队列**
- `PutCargoQueueLength` 表示队列长度
- `Exchange(amount)` 才真正结算
- **为什么要队列**：防"投一堆货瞬间换钱跑路"，给其他玩家/警察反应时间
