## 0. 一页结论

1. **帮派 = 产权单位**：能占区、能占产业、能收税；**队伍 = 临时同步单位**：不能占产权。两者**必须分开**。
2. **4 阶 × 11 权限**：`ClanRankDescription` 的 11 个布尔权限位，4 个阶（Leader/Officer/Fighter/Recruit）。
3. **帮派配置 10 项**：`ClanConfig` 含两个冷却（建帮/入帮）、两个上限（成员/申请）、两个过期（申请/邀请）、一个情报配额（`GetInfoResourceDescription`）。
4. **帮战是"预约赛"**：`ClanConquestObjectTypeDescription` 有 `ClanBattleBetMinAmount`（下注下限）、`ClanBattleTier`（分档）、`ClanBattleBet`（认领）。
5. **区主/州长是"帮派身份"**：区主必须"相邻区已被本帮控制"；影子州长必须"控制 Highlands 的帮主"。
6. **换州 = 退帮**（`switch_realm_in_clan_warning`）；**帮战必须退队**（`party_can_not_enter_to_clan_battle`）。

## 1. 帮派 vs 队伍：两个系统，不能混

| 维度 | Party 队伍 | Clan 帮派 |
|---|---|---|
| 本质 | 临时同步单位 | 永久产权单位 |
| 规模 | 小（`party_full_validation` = "Party is full"） | `ClanConfig.MaxMembersCount` |
| 存续 | 出图/换场景可能解散 | 持久 |
| 产权 | **无** | **有**（区/产业） |
| 决策 | 队长 | 4 阶 + 权限位 |
| 一起进战斗 | 可以（`realm_party_entry` = "enter together"） | 帮战单独一套 |
| 与帮战互斥 | **帮战必须退队**（`party_can_not_enter_to_clan_battle` = "You must leave the party"） | — |

## 2. `ClanConfig`（dump.cs:106061）—— 10 项配置

```csharp
public class ClanConfig {
    int MaxDescriptionLength;                      // 帮派简介上限
    int CreateCoinsAmount;                         // 建帮成本（币）
    long CreateClanCooldown;                       // 建帮冷却
    long JoinClanCooldown;                         // 入帮冷却（防跳帮）
    int MaxMembersCount;                           // 成员上限
    int ClanMaxRequestsCount;                      // 待审申请上限
    long RequestExpirationTime;                    // 申请过期
    long InviteExpirationTime;                     // 邀请过期
    int AvailableForJoinClansListMaxCount;         // 可申请帮派列表上限
    ExpiringResourceDescription GetInfoResourceDescription;  // ← 查询帮派详情的配额
}
```

`[实证]`

**两个"冷门但重要"的字段**：
- `JoinClanCooldown`：**防帮战期间跳帮搅局**（否则可以"打不过就跳对面"）
- `GetInfoResourceDescription`：**连"看别人帮派资料"都要消耗配额**（防爬/防侦察，同时让"侦察"变成有成本的战略行为）
