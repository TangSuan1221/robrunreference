## 0. 一句话结论

ROB RUN 的"局外"不是菜单，而是**四层空间 + 两套产权 + 三条时间轴**：

- **四层空间**：`Region（延迟大区） → Realm/State（寿命有限的服务器） → Sector/District（10 个，Tier 1/2/3） → Settlement（聚落） → Plot（地块） → Slot（槽位）`
- **两套产权**：**聚落产权**（用 Settlement Title 物品买断，可收税、可驱逐、上限 `OwnedSettlementConfig.MaxCount`）与**地块产权**（用 Land Plot Title 租，绑定个人，换租=整体搬家，不可被抢）
- **三条时间轴**：**秒/分**（建造、破门、开箱）→ **小时**（洗钱、税生效、贸易刷新）→ **天/周**（帮战排期、州寿命、联邦没收）

所有"局外系统"都围绕这三件事展开：**拿到空间使用权 → 在空间里放置生产设施 → 让产出在可被掠夺的空间里变现**。

## 4. 空间与产权总览（后续所有文档的地图）

```
Region（3：Asia / Europe / North America）        ← 延迟分区，可换，只在监狱里可换
  └ Realm / State（动态并发，每个 StartTs + Lifetime）  ← 「服务器」，换州=进度丢失
      └ Sector / District（10 个，命名 0..9）          ← 帮派争夺单位，Tier 1/2/3
          └ Settlement（每区 N 个）                    ← 可被玩家买断的「聚落」，有主/无主
              └ Plot（每聚落 N 块，preset 点阵）        ← 玩家「家」，用 Land Plot Title 租
                  └ Slot（32 种类型）                  ← 建造原子单位，放 InventoryItem
```

**四个数量字段决定社会结构**（`[实证]` 字段存在；值 `[未知-服务端]`）：

| 字段 | 所在类 | 作用 |
|---|---|---|
| `OwnedSettlementConfig.MaxCount` | `Models.References.Realm` | 单人最多持有几个聚落 |
| `PlotSpotConfig { MaxPresetsCount, EmptyPresetIndex, MaxSpotsCount, EmptySpotIndex }` | `Models.References.Plot` | 地块点阵与预设布局 |
| `TierParams.SectorSettlementsCount` | `Models.References.Realm` | 每个区的聚落数 |
| `RealmParams { UsersLimit, Lifetime, RecommendedUsersCount, RecommendedLifetime }` | `Models.References.Realm` | 州容量与寿命 |

## 9. 本系列的"三个不写"

1. **不写没证据的数值** —— 所有服务端数值都进 `Unknown 清单`，不拍脑袋。
2. **不把"推断"伪装成"实证"** —— `[推断]` 一律附推理链，`[实证]` 一律附行号/文案/字段。
3. **不重复既有文档** —— 既有 7 份文档已有的结论只引用不重写，本系列只补缺口。
